# 暫定ヒーロー画像

`onokoro.webp` は、利用者が選んだイザナギ・イザナミとおのころ島の生成画像を、同じ寸法（1641 × 958）で WebP 品質90に変換したもの。2026-09-14 に使用を指定された。神話を題材とする創作イラストで、史料の複製ではない。

元画像のファイル名：`exec-7b578017-2c0e-46e0-b30c-a44dfa472320.png`。制作ツールは組み込みの画像生成。藍色と金、日本画・和紙・紬の織り目、二柱と矛先の雫から島が生まれる構図を指定して作成した。

`tools/scripts/build-public.ts` が WebP を埋め込み、`public/images/onokoro-hero.svg` を生成する。SVG は外部画像に依存しない単体ファイルで、画像のパス化はしていない。SVG のタイトル・説明と HTML の見出し・本文・代替説明は `src/i18n/locales/ja/home.ts` の `hero` が正本。

画像内の文字は元絵に描き込まれている。コピーを変えるときはカタログと元絵を同時に更新する。本採用時には絵と文字を分離し、すべての表示文字をカタログから生成する（ADR 0005）。
