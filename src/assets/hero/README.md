# 暫定ヒーロー画像

`onokoro.webp` は、イザナギ・イザナミとおのころ島を描いた生成画像の背景画。1641 × 958、WebP 品質90。神話を題材とする創作イラストで、史料の複製ではない。

承認済みのファイルの SHA-256 は `8a74eca63b3425acc9cffa0f4673e5c69cdc9e4371d5df0753f14b32869c2ebd`。`tests/content-routing.test.tsx` が照合する。絵を差し替えるときは、文字が描き込まれていないことを画面で確かめてから、テストの値とこの行を更新する。

2026-09-14、利用者が選んだ元画像 `exec-7b578017-2c0e-46e0-b30c-a44dfa472320.png` から、組み込みの画像編集で文字を除いた。編集後の原本は `exec-d95b292b-ab75-4bb9-b7a5-22a2d0410506.png`。文字を除くため背景の一部は再生成されている。元の文字入り画像は Git の履歴に残る。

`tools/scripts/build-public.ts` が背景画を埋め込み、`public/images/onokoro-hero.svg` を生成する。外部画像に依存しない単体ファイルで、画像のパス化はしていない。

2026-09-17、SVG のキャンバスを **1920 × 960（2:1）** に変更。元の WebP（1641 × 958）は加工・再圧縮せず、縦横比を保って右へ配置し、左右の縁を透過グラデーションで背景へなじませる。左にコピーの余地を確保し、PC では画像全体を表示する。表示領域は最大幅 1920 px・通常の高さ 380〜720 px。コピーの拡大時は切らずに領域を伸ばす。モバイルでは右寄りの人物を基準に左右を切る（[ADR 0061](../../../docs/architecture/0061-responsive-hero-canvas.md)）。SVG のキャンバス寸法は画質の向上を意味せず、内包画像の解像度とファイル容量は維持する。

**文字を画像に描き込まない。** 見出し・本文・代替説明の正本は `src/i18n/locales/ja/home.ts` の `hero`。見出しと本文はHTMLとして描画し、すべての幅で背景に重ねる（ADR 0029）。SVGのタイトルは絵の説明のみ。コピーの変更に画像編集は不要（ADR 0019）。
