# 料金再設計の判断用モデル

公開価格を変更しない、経営判断用の独立した計算モデル。Node.jsの標準機能だけで実行する。

```sh
node --test tools/pricing/model.test.mjs
node tools/pricing/report.mjs
```

- `proposal.json`: 提案価格と仮定。140時間はユーザー指定。それ以外の時間・費用・解約率・顧客構成は未検証の入力。
- `model.mjs`: 単価の下限、月の納品容量、本人時間を含む余力、顧客総額、解約を加味した顧客数を計算。
- `report.mjs`: JSONレポート。工数超過時の収支は追加人員費を含まないため、`feasible: false` のケースを達成可能な利益として扱わない。
- `model.test.mjs`: 不利な比較、工数超過、本人原価の二重計上、解約率による到達不能、入力値を検査。

詳細は [料金再設計](../../docs/business/pricing-redesign-140h.md)。公開料金の正本は `site/src/content/prices.ts` のまま。採用時は提案と実測を確認して公開価格へ移し、二つを同時に正本として運用しない。

利益の表示は税込・税引後手取りではない。時間単価5,000円は本人の月140時間を70万円として評価するための仮定で、追加の人件費を二重に引かない。現金獲得費は広告・紹介など本人の作業時間を含まない費用のみ。外部サービスの顧客直接払いは紬の売上・経費に含めず、顧客総額に加える。

比較先は公開情報の参考値で役務は一致しない。`customerTotal` の36か月超は比較先が月額契約を継続する場合だけ。譲渡を選ぶ場合は別の外部費見積もりが必要。算出される `breakEvenMonth` もこの継続仮定に限られる。
