## 検証している項目

`verify` が見ているもの。**1件でもFAILがあれば `exit 1` になります。**

- 全ページに `tel:` リンクがあり、番号が**文字**で入っている（画像の電話番号は不可）
- 営業時間・住所が文字で入っている
- `lang="ja"` / viewport / `h1` がちょうど1つ
- JSON-LD が valid で、`@type` `name` `address` `telephone` が揃っている
- `FAQPage` が混入していない
- 全 `<img>` に `alt` がある。**先頭画像に `loading="lazy"` が付いていない**
- 実行時JSが無い（`<script>` もインラインイベントハンドラも0件）
- 内部リンクがすべて解決する
- CSSカスタムプロパティが全部定義されている（未定義参照の検出）
- フォームの `<label for>` と入力の `id` が一対一で対応している
- 料金ページに全プランの金額が載っている
- 業種別ページが4本ある
- **`design.tokens.json` と `tokens.css` が同期している**（ずれていたら納品しない）
- **採用した寸法・色15項目が出ている**（ヘッダーはADR 0006の88/72px、315×57、260×48、1104px、720px、45/24px、アイボリー `#FFF8ED`、エスプレッソ `#302820`、琥珀 `#FFB000`（ADR 0014）、角丸…）
- **使わないと決めた値が混入していない**（`#858A95`、旧Shipporiフォント、外部フォントの読み込み。屋号の端末明朝はADR 0006で採用）
- **全ページに og:image があり、その画像が out に実在する**（真っ白な共有カードを出さない）
- **ファビコンと apple-touch-icon が入っている**
- `src/content/config.ts` に仮の値が残ったまま公開されようとしていないか
- title / description の長さ、ページ容量

### ブラウザ実測（Playwright + Chromium）
- **LCP 2.5秒以内**（全ページ・`PerformanceObserver` の実測値）
- **横スクロールが発生しない**（幅390px＝ガイドの検証寸法）── 自前で `overflow-x` を持つ器は除外
- **タップ領域 44px以上**（幅390px・本文中のインラインリンクは除外。WCAG AA の最小は24pxで、44pxは本ガイドの推奨値）
- **コントラスト比 WCAG AA**（34箇所。フォント実サイズと太さから大文字判定を分ける）
- **図の色が良／悪で区別できるか**（同色になると帯や印の意味が消える）
- **図のコントラスト比 WCAG AA**（全ページ。SVGの `<text>` は `color` ではなく `fill` と
  `opacity` で色が決まるので、本文用の検査では捕まらない。合成してから最悪値を出す）
- コンソールエラーが無い
- スクリーンショット出力（`shot-desktop.png` / `shot-mobile.png` / `shot-price.png`）

### 検証で実際に見つかった不具合

この仕組みを作った初回で、**目視では気づきにくい3件**が出ました。

1. **ヘッダーの電話番号が赤地に赤で描画されていた。**
   `.tel .num` が、表のバツ印用に定義した `.no{color: 琥珀}` を拾っていたCSSのカスケード衝突。
   → コントラスト検査に `.tel .num` を追加して、機械で捕まえられるようにしました。
2. **13ページで `<h1>` が0個だった。**
   セクション見出しが全部 `<h2>` だったため。
   → ページの先頭の見出しを `h1` にすることを不変条件にして（`<Section h1>`）、`verify` が検査します。
3. **1ページだけタップ領域の判定が誤検出していた。**
   CSS適用前に計測していた競合状態。
   → スタイルシートの適用完了を待ってから計測するようにしました。
4. **図の琥珀色の注記が、エスプレッソ紺の節の上で 2.94:1 しか出ていなかった。**
   SVGの `<text>` は `fill` で色が決まるため、本文用のコントラスト検査を素通りしていました。
   → 図専用の検査を足し、`section.dark .fig` でトークンを明るい側に振り替えました。
