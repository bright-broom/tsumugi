# サイトの主張と値付け

事業としての規範は [ビジネスガイドライン](../business/紬_ビジネスガイドライン.md) が正本。
ここには、それを**このサイトでどう表現し、どう検査しているか**を書く。

> 文中のコードのパス（`src/…` `scripts/…` `verify/` `styles/` `public/` `out/`）は `site/` からの相対。

---

## 主張の設計

サイト全体で言うことは1つです。

> いま制作会社に作ってもらっているホームページは、土地でいえば**借地権**にあたる。
> 紬がつくるのは、お客様が**所有権**を持てるホームページ。

この主張を、気分の話で終わらせないために**4つに分解して、それぞれ検証できる形**にしています。
`owned.html` が主張の本体で、他のページはその材料です。

| 所有の中身 | 何をもって所有と言えるか | どこで確かめられるか |
|---|---|---|
| **① 住所** ドメイン | 初日からお客様の名義で取得する | ドメインの公開登録簿 |
| **② 建物** ソースコード | 一式を納品し、利用・改変・移管を制限しない | 契約書（`terms.html`）・`source.html` |
| **③ 地盤** 置き場所 | 実行時JSが0バイトなので、どのサーバーにも置ける | `verify` の「実行時JSなし」 |
| **④ 家具** 写真と原稿 | 撮影の元データを用途の制限なく渡す | 契約書（`terms.html`） |

**あえて自分の喩えを弱めている箇所があります。**
借地借家法には更新拒絶の正当事由（6条）と建物買取請求権（13条）があるので、
**本物の借地のほうが月額制のホームページ契約よりずっと守られています。**
`owned.html` はそれを表で認めたうえで、「いまの契約はむしろ定期借地（更地返還）に近い」と続けます。
都合の悪い事実を先に出したほうが、残りの主張が通ります。
なお法律の話には「弁護士ではない／契約書が優先」の断りを必ず添えています。

図 `land_vs_own` は、この主張の視覚版です。**左右の建物をわざと同じ見た目にしてあります。**
違いは土地の名義と、解約したあとに手元に残るものだけ、というのが図の主張だからです。

検証にも入れてあります。`verify` の **26「主張の一貫性」**が、
トップと `owned.html` の両方に「借地・所有・名義・ソースコード」が揃っていることを検査し、
片方だけの言い回しになったら落ちます。

## 値付けの設計（2026-09-14改定）

制作は79,800円 / 198,000円 / 398,000円、継続支援は0円 / 4,800円 / 9,800円 / 29,800円（月額）。いずれも税別。金額の唯一の正本は `site/src/content/prices.ts`、表示文はi18nで管理する。

入口も単体で採算を取る。将来の支援契約で赤字を取り戻す設計にはしない。月140時間のうち28時間を営業・事務、28時間を予備に取り、契約作業は84時間以内にする。

支援は月単位・前月末申出で変更可能。通常の変更枠は「整える」30分、「育てる」90分＋打合せ30分。「守る」には通常変更を含めない。撮影と外部サービスは別見積もり。制作は着手50%・検収50%、自社24回分割を新規に売らない。

払い直しを減らす充当は同一事業・再利用できる増築・納品12か月以内・1回の条件を必ず併記する。CMS付き「情報を育てる」は受付準備中。提供確認前に売らない。

外部費は**月3,500円の仮置き**。Vercel Pro・ドメイン・従量分等の概算枠であり、見積時には通貨、座席、税、フォーム/CMSの有料枠を確認して置き換える。VercelのHobbyは非商用向けであり、事業サイトを無料運用する前提は置かない。[Hobbyの利用範囲](https://vercel.com/docs/plans/hobby)、[Proの公式料金](https://vercel.com/pricing)（2026-09-14確認、Proは月20米ドル〜。追加座席・従量等を別途確認）

| ページ規模 | 紬の制作＋「守る」＋外部費 / 36か月 | 比較先の公開料金 / 36か月 | 紬−比較先 |
|---|---:|---:|---:|
| 1ページ | 378,600円 | 357,800円 | ＋20,800円 |
| 6ページ | 496,800円 | 537,800円 | −41,000円 |
| 9ページ / 比較先7〜12ページ | 696,800円 | 717,800円 | −21,000円 |

**同じ役務を安く売っているという比較ではない。** 比較先には月5回の変更、紬の「守る」には変更作業を含まない。月5回更新したい顧客に、この表で割安だと言わない。比較先のドメイン・サーバー管理は掲載月額に含まれるが、個別オプションは見積もりで追加する。36か月を超えると比較先の譲渡・契約継続の選択があるため、その後の固定月額を一律に外挿しない。

6ページで紬の「整える」を選ぶ場合、同じ外部費仮定で36か月676,800円となり、比較先より139,000円高い。所有・作業の中身・費用差を並べ、価値がない相手には提案しない。1ページを自分で管理する場合は205,800円だが、保守・更新の労力も自分で負担する。

改善案件は、売上額ではなく「追加1件が生む限界利益」で判断する。例えば制作198,000円を24か月で按分し、整える9,800円＋外部費3,500円なら月21,550円。追加1件の限界利益が10,000円なら、月3件が単純回収の目安。これは目標の計算であって、問い合わせや受注の予測ではない。既存の費用が確実に削減できる場合はそれを差し引く。

`compareRows()` と検証コードで価格を確認する。社内モデルの写しとの一致もテストする。比較先の出典と確認日を示し、役務が異なる比較を最安値保証に使わない。詳しい原価と判断基準は [月140時間の料金設計](../business/pricing-redesign-140h.md)。

## 説明文の行き先（約束を書いておく場所）

「変更は合意した月次作業枠内」「やめてもサイトは残ります」と本文で言う以上、
**その条件が書いてある場所が要ります。**ないまま言うと、ただのうたい文句になります。

| ページ | 何のために要るか |
|---|---|
| `owned.html` | 主張の本体。借地との対応表、法律の正確な話、所有の4要素、5つの確認質問、移行手順 |
| `terms.html` | サイト上の約束の根拠。所有権の扱い・解約したときの扱い・変更の範囲・できないこと |
| `flow.html` | 「約6週間でお渡し」の中身。10手順と、補助金を使う場合の順序の違い |
| `faq.html` | 電話の前に確かめたいこと。**FAQの構造化データは付けない**（2026年5月に検索表示が終了） |
| `privacy.html` | 問い合わせフォームが個人情報を取るので必要。**アクセス解析もCookieも入れていない**ことを明記 |
| `legal.html` | 特定商取引法に基づく表記。価格を出して役務を売る以上、置いておく |

`verify` の **25「必須ページ」**が、この4枚（owned / terms / privacy / legal）の存在と、
**全ページから1タップで到達できること**を検査します。フッターの下段に別枠で置いてあります。

## 屋号

**「紬（つむぎ）」に決定。**`src/content/config.ts` の `BRAND` / `BRAND_READING` / `LEGAL_NAME` に入っています。

一文字の屋号なので、次の3つを実装で担保しています。

- **ロゴに読みを添える**（`BRAND_READING`）。`.logo.one` が字を主役にして「つむぎ」を小さく置く
- **ロゴの脇に業種を必ず出す。** 一文字だけでは何屋か伝わらないため、狭い画面でも `.s2`（短縮版）に切り替えて落とさない
- **`<title>` は業種を先に置く。** 「紬｜…」ではなく「〈エリア〉の小規模事業者のホームページ制作｜紬（つむぎ）」。一文字を検索結果の先頭に置いても意味を成さないため

屋号で指名検索はされない前提の設計です（流入は「地名＋ホームページ制作」で取る）。

**未了：** 商標（J-PlatPat 第42類・第35類）、同名法人（法人番号公表サイト）、ドメインの3点確認。
一文字漢字は既登録が多いので、公開前に必ず調べること。
