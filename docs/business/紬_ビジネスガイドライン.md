# 第 I 部　社内の運営規範

## 1. この事業は何か

### 1.1 定義

小規模事業者に対して、**その事業者が所有権を持てるホームページ**を制作し、その後の運用を引き受ける事業。
2 名体制。
地域は限定せず全国。
打ち合わせ・取材・修正はオンラインと電話で完結し、出張するのは撮影のときだけ。

### 1.2 対象

| | |
|---|---|
| 業種 | 飲食店／工務店・建設／美容室・サロン／士業・専門事務所 |
| 規模 | 従業者 5 人以下を中心とする小規模事業者 |
| 状態 | ホームページを持っていない、またはポータルサイト・SNS だけで済ませている |

従業者 5 人以下のホームページ開設率は約 30% で、全体の 48.2% を大きく下回る。
業種別でも卸売・建設・不動産が約 30% で最低。
**市場は「まだ持っていない人」の側にある。**
（出典：Wepage 2025 年 7 月調査・n=3,000）

### 1.3 やらない事業

- 人を増やして件数をこなす形にはしない。
- 効果の根拠がないものを商品にしない（第 7 章）。
- 名指しで他社を叩く商売はしない。比べるのは仕組みであって会社ではない。

## 2. 主張の軸

### 2.1 一番の主張

> いまのホームページ制作会社が作るサイトは、土地でいえば**借地権**にあたる。
> 紬が作るのは、お客様が**所有権**を持てるホームページ。

この 1 文がすべての起点。
料金も、仕様も、契約書も、断る基準も、ここから導かれる。
**この主張を崩す判断は、どれだけ儲かってもしない。**

### 2.2 「所有」の定義

気分の話にしないため、4 つに分解し、それぞれ確かめられる形にしてある。

| | 中身 | 確かめ方 |
|---|---|---|
| ① 住所 | ドメイン | 公開の登録簿でお客様の名義を確認できる |
| ② 建物 | ソースコード一式 | 契約書に納品物として明記。GitHub に閲覧権限で招待 |
| ③ 地盤 | 置き場所 | 実行時 JavaScript 0 バイトなので、どのサーバーにも置ける |
| ④ 家具 | 写真・原稿の元データ | 用途の制限を付けずに渡す |

**③ が技術の話に見えて、実は営業上いちばん効く。**
サイト作成ツールで作られたページは書き出せる形になっていないため、「譲渡」されてもツールの外へ持ち出せない。
紬は HTML と CSS のまま渡すので、置き場所を選ばない。

### 2.3 喩えを弱めることで強くする

**本物の借地のほうが、いまのホームページ契約より守られている。**
ここを正直に書くことで、残りが信用される。

| | 契約の更新 | 終わったときに残るもの |
|---|---|---|
| 普通借地権 | 地主は正当な事由がなければ拒めない（借地借家法 6 条） | 建物を時価で買い取らせられる（同 13 条） |
| 定期借地権 | 更新なし（同 22〜24 条） | 買取請求できない。更地にして返す |
| 月額制のホームページ | 契約書しだい | 買取の規定がないことが多い。公開が止まる |

**必ず添える但し書き**：当方は弁護士ではない。
条文は仕組みを説明するための引用であり、個別契約の効力を判断するものではない。
実際の条件は契約書で確認していただく。

### 2.4 主張を技術的に支える不変条件

以下が崩れると、②③ の根拠が同時に消える。
**変更する前に必ず検査を通す。**

| 不変条件 | 現状 | 崩れると何が起きるか |
|---|---|---|
| 実行時 JavaScript 0 バイト | 全 21 ページで 0 件 | 「どのサーバーにも置ける」が言えなくなる |
| 表示速度 2.5 秒以内 | 実測 0.18 秒 | 納品条件を満たさない |
| 自動検査 581 項目 PASS | 0 FAIL | 「1 つでも落ちたら納品しない」が嘘になる |
| ドメインはお客様名義 | 運用ルール | ① が消える |

ページに `export const config = { unstable_runtimeJS: false }` を置き忘れるか、App Router に移すと、実行時 JavaScript が載る（置き忘れはビルドが止まる）。
**変更したら必ず `npm run build && npm run verify` を通すこと。**

## 3. 値付けの規範

### 3.1 金額（税別）

| 制作 | ページ数 | 買い切り | 分割初回 | 分割月額 ×24 | 分割なら毎月※ |
|---|---|---|---|---|---|
| シングル | 1 | 39,800 円 | — | — | — |
| ベーシック | 6 | 198,000 円 | 30,000 円 | 7,000 円 | 16,800 円 |
| **スタンダード** | **9** | **398,000 円** | **110,000 円** | **12,000 円** | **28,000 円** |
| プロ | 14 | 698,000 円 | 218,000 円 | 20,000 円 | 49,800 円 |

※ 制作費の分割分＋そのプランに合わせた運用月額。

| 運用（月額） | 金額 | 想定 |
|---|---|---|
| ライト | 5,800 円 | シングルを動く状態で保つ最小構成 |
| ベーシック | 9,800 円 | 作ったあとを維持する最小構成 |
| **スタンダード** | **16,000 円** | Google マップからの来店を増やす運用まで |
| グロース | 29,800 円 | 広告と掲載費の全体を見直すところまで |

契約は 3 か月単位。違約金なし。

### 3.2 値付けの 5 原則

1. **業種で値段を変えない。** 変わるのはページ数と作るページの中身。
2. **分割の総額は買い切りと同じ。** 手数料 0 円。金融機関を通さないので、手数料を請求する理由がない。
3. **上の段に移るときは差額のみ。** 最初に払った額を充当し、払い直しにしない。契約書にも同じ条項を置く。
4. **サブスクにしない。** 理由は 3.4。
5. **値引きで取らない。** 値引きするくらいならページ数を減らす。金額を動かすと、次のお客様に説明できなくなる。

### 3.3 「1 ページから」の位置づけ

シングル 39,800 円は**入口商品であって主力ではない。**
役割は「請求書を 1 枚出して、関係を始めること」。
主力はスタンダード 398,000 円。

シングルに**含めないもの**を守る。

- 出張撮影（ベーシック以上には標準で含む）
- ご自身で更新する管理画面（スタンダード以上）

ここを入れると原価が合わず、値段の説明もできなくなる。

### 3.4 サブスクにしない理由

月額 9,800 円が成立するのは、**36 か月のリースだから**（1 ページで総額 357,800 円）。
納品物がサイト作成ツールなので、相手のビルド原価は構造的にほぼゼロ。
手で作るこちらが同じ形をとると、原価が合わない。

それ以上に重い理由がある。
**サブスクにすると「払い切るまで渡さない」という相手と同じ構造になり、所有権の主張そのものが崩れる。**
買い切りのまま入口を下げる、が唯一の筋の通し方。

### 3.5 総額の並び（負けている行を消さない）

36 か月で並べる。
36 か月は相手が「無償譲渡」の区切りに置いている期間であって、こちらの都合ではない。

| ページ数 | 月額制 36 か月 | 紬 36 か月 | 差 |
|---|---|---|---|
| 1 ページ | 357,800 円 | **248,600 円** | **109,200 円 安い** |
| 6 ページ | 537,800 円 | 550,800 円 | 13,000 円 高い（月 361 円） |
| 12 ／ 9 ページ | 717,800 円 | 974,000 円 | 256,200 円 高い |

**負けている行をサイトにも見積書にも出す。**
差の中身（出張撮影・取材による原稿・修正の回数制限なし・Google マップ運用）を隣に書き、「素材が手元にあって更新もしない方には月額制のほうが向いています」と明記する。
**都合の悪い行を消すと、勝っている行も信用されない。**

### 3.6 期間が短いと逆転する（営業上の最重要事項）

36 か月はこちらの土俵。
お客様が 12 か月で考えているなら、結論は変わる。

| | 月額制 12 か月 | 紬 12 か月 |
|---|---|---|
| 1 ページ | 122,600 円 | 109,400 円（運用なしなら 39,800 円） |
| 6 ページ | 182,600 円 | **315,600 円** |

→ **短期しか見ていない相手に、ベーシック以上を売ってはいけない。**
シングルで入って、効いてからページを足す。
これが営業上の正解。

商談で必ず聞く：**「何年くらい使うつもりですか」。**
3 年以上ならスタンダードを出す。
1 年で考えているならシングルを出す。
ここを外すと、売った直後から不満が始まる。

## 4. 営業

### 4.1 リストの作り方

Google Places API で対象エリアを総ざらいし、ホームページ未保有／ポータル依存の店を抽出する。
スクリプトは `leadfinder`。

| | |
|---|---|
| 抽出 | `websiteUri` が空＝なし／食べログ・Instagram・ホットペッパー・LINE のみ＝ポータル依存。**両方を対象にする** |
| 優先度 | 口コミ数 45 ＋ 評価 20 ＋ 電話番号 20 ＋ サイト状態 15（0-100） |
| エリア基準 | 人口 10〜30 万の地方中核市／県庁所在地を外す（制作会社が薄い）／建設・卸売・不動産の比率が高い／従業者 5 人以下が多い |

**規約上の制約（必ず守る）**：Places API のコンテンツは恒久保存・DB 化が不可。
恒久保存できるのは `place_id` のみで、その他は 30 日以内に破棄する。
運用は「自社台帳には `place_id` と自分でヒアリングした内容だけを残し、Excel は 30 日サイクルで再生成して使い捨てる」。
商談に入った先は、自前で確認した情報として別管理へ移す。

優先度スコアは受注実績ではなく仮説。
**商談を 10 件回したら、配点を実績で調整する。**

### 4.2 初回接触で聞く 3 つ

1. いまホームページはありますか。
2. いま掲載費や広告費をいくら払っていますか（おおよそで可。請求書があれば見ながらのほうが早い）。
3. いちばん困っていることは何ですか。

この 3 つで、**その場で概算を出す。**

### 4.3 商談の順番

新しい予算をつくる前に、いま出ている費用を見る。
**これが紬の商談の型。**

1. 3 つの数字を聞く（掲載料／手数料／そのサイト経由の月間新規数）。
2. 新規 1 人あたりの獲得コストを一緒に計算する。**多くの店主がこの数字を見るのは初めて。ここだけでも意味がある。**
3. そのお客様の粗利と比べる。1 人 5,000 円かけて獲得した客の粗利が 3,000 円なら、そのプランは合っていない。
4. 3〜6 か月の併走計画を作る。**いきなりポータルをやめない。**
5. 契約の更新月に合わせてプランを下げる。「いますぐ安くなります」とは言わない。

送客手数料はディナー 1 人 220 円・ランチ 110 円（税込）で、**新規と常連を区別しない。**
いつも来てくださる方がネット予約するたびに 220 円かかる。

**運用スタンダード 16,000 円は、ディナー予約を月 73 人分だけ自社サイトに移せば出る金額**（16,000 ÷ 220 ＝ 72.7）。
毎晩 4 名 ×30 日＝月 120 人の店なら、送客手数料だけで月 26,400 円払っていることになる。

### 4.4 業種ごとの財源

| 業種 | どこから出すか |
|---|---|
| 飲食店 | 食べログ。**ベーシック（税込 27,500 円）を無料プランに戻しても、ネット予約は固定費 0 円で使える**（手数料の単価は有料プランと同じ。同社が公式に明記）。予約を失わずに掲載料だけゼロにできる |
| 美容室 | ホットペッパービューティー。**掲載料は非公開なので推測で金額を言わない。直近の請求書を見せてもらう。** 無料プランは存在せず、予約売上の 2% が手数料 |
| 工務店・士業 | 広告費。止めるのではなく入札単価を下げる。商圏外への配信停止、成約ゼロの検索語の除外 |

**ライトプラン（11,000 円）と無料掲載の店には、この話は使えない。**
1 段下げても 11,000 円で、運用スタンダード 16,000 円に届かない。
**店のプランを確認せずに「1 段下げれば出ます」と言うのは不誠実。最初に必ず聞く。**

### 4.5 広告について

「やめましょう」とは言わない。
止めた実測例では、自然検索の流入は一時的に増えたものの続かず、**予算 3.45 倍に対して売上は 1.07 倍**だった。
正解は止めることではなく入札単価を下げること。
別の事例では約 30% 下げながら検索結果上部にほぼ常時表示されている。

### 4.6 いまの実力を直視する

競合（サブスク型・105 名体制）との差は、**価格ではない。**

| | 相手 | 紬 |
|---|---|---|
| 実績 | 8,017 件 | 0 件 |
| 自社サイト経由の問い合わせ | 月 1,500 件 | 未設計 |
| 制作費 | 0 円（初期 5,000 円） | 39,800〜698,000 円 |

**6 ページ級では 36 か月の総額がほぼ同じ（差 13,000 円＝月 361 円）。値下げなしで勝てる。**
勝負がつくのは、その金額で「途中でやめたら消えるサイト」か「初日から自分のもの」かの選択。

一方、**入口の重さと実績 0 件は事実として重い。**
ここを埋めるのは価格ではなく、①1 件目の数字を全部出すこと、②集客経路を設計すること。
**集客経路は未設計のまま。これが現在いちばん大きな穴。**

### 5.3 納品条件

**20 項目すべてを満たすこと。1 つでも落ちたら納品しない。**
検証は機械で行う（`site/verify/`／581 項目）。

区分は 4 つ。

| 区分 | 中身 | 根拠の性格 |
|---|---|---|
| 情報（6 項目） | 電話・営業時間・住所地図・料金・電話とフォームの主役・対応エリア | 調査で「連絡されない理由」の 1 位と 2 位 |
| 中身（5 項目） | 写真・顔写真・実績事例・お客様の声・解説記事 3〜5 本 | 見た人が判断材料にしているもの |
| 技術（6 項目） | スマホと PC で同内容・2.5 秒以内・遅延読み込みの設定・スコア満点は狙わない・44px のタップ領域・構造化データ | 数字で効果が確認できるものだけ |
| 運用（3 項目） | GBP リンクの正しい紐付け・通知 2 系統と返答時間・口コミの鮮度 | 作ったあとに効く部分 |

覚えておくべき数字：

- 料金が不明確は「連絡しなかった理由」の 2 位（32%）で、星の評価（30%）より上。**ただし安さは訴求しない**（税理士選定で「低価格」を最重視した人は 7.2%）。
- 業種で電話とフォームの主役が逆転する。士業は電話 56%／フォーム 44%、美容室はフォーム 92%／電話 8%。
- スマホで 2.5 秒を満たしているサイトは 62% しかない。写真が主役の店は構造的にここで遅くなる。
- タップ領域は国際指針の最低 24px ではなく **44px**。読み手が 50〜60 代であることを前提にする。
- 74% が直近 3 か月以内の口コミを重視、47% は口コミ 20 件未満の店を使わず、42% は返信していない店を避け、50% は定型的な返信だと選ぶ確率が下がる。

## 6. 運用

### 6.1 「無制限」の境界

**「無制限」と書く以上、どこまでかを同じ場所に書く。曖昧にすると必ず揉める。**

何回でも無料：文章の修正・写真の差し替え・メニュー／料金の変更・営業時間／定休日の変更・お知らせの投稿・スタッフの追加／入れ替え・施工事例／スタイルの追加・リンクの修正・既存ページ内の並べ替え。

別途お見積り：新しいページの追加（33,000 円／ページ）・デザインの全面変更・他社サイトからの移管・新しい機能の追加・ロゴ新規制作（88,000 円）・撮影の追加（半日 55,000 円／1 日 88,000 円）。

### 6.2 運用の 3 つの約束

1. **依頼の窓口はひとつにする。** 電話・LINE・メールに散ると対応漏れが起きる。納品時に窓口を決める。
2. **作業した時間を記録して毎月知らせる。** 測っていない「無制限」は信用できない。
3. **3 か月の平均で大きく超えた場合だけ上位プランを案内する。** その場で断ったり追加請求したりしない。

想定は月 1〜2 時間。
超えても追加請求しない。
ただし 3 か月平均で月 4 時間を大きく超える場合は、次の更新で相談させていただく。

### 6.3 運用の中心は口コミの鮮度

ホームページを直すことより、Google マップの投稿と口コミへの返信のほうが来店に効く。
スタンダード以上ではここを代行する。

## 7. 売らないもの・約束しないもの

### 7.1 売らないもの

根拠がないものは商品にしない。
**これらを売っている制作会社は実際にある。同じ商品棚に並ばないことが、いちばんの違い。**

| 売らないもの | 理由 |
|---|---|
| AI 検索対策（LLMO） | Google の公式ガイドが「生成 AI の検索に構造化データも AI 向けの書き方も不要」と明記している |
| 検索順位の保証 | Google が公表していない要因を保証できる者はいない |
| 記事の量産 | ページ数と引用されやすさの相関はほぼゼロ |
| 表示速度スコアの満点 | Google 自身が「SEO のために満点を狙うのは時間の使い方として最善ではない」と書いている |
| Google の飲食店カルーセル狙いの設定 | 限られた事業者にしか表示されない機能なので、狙っても意味がない |

### 7.2 約束しないもの

- 検索で 1 位になること。
- 新規のお客様が増えること（美容室の市場は前年比 5.9% 縮小）。
- 補助金の採択（採択率 47.2%）。

**確実にできるのは、手数料の削減と再来店の導線づくり。そこは数字で確認できる。**

### 7.3 断る基準

以下は受けない。

- 法令に反する内容、事実と異なる表示。
- 反社会的勢力に関係する場合。
- 掲載する情報（料金・資格・実績）が事実でない、他人の文章・写真を無断で使うことを求められる場合。
- 順位保証・集客保証を契約条件として求められる場合。
- **弁護士の広告規制に触れる表現を求められる場合**（日本弁護士連合会の会規で、誇大な広告・他の弁護士との比較・勝訴率の表示が禁止。顧問先の掲載には書面での同意が必要）。

### 7.4 「やめないでください」と言う基準

ポータル掲載の見直しは主力商品だが、**次のいずれかに当てはまる店には、やめるのは危険だと伝える。**

- 既存客の連絡先が整理されておらず、再来店の導線がない。
- 再来店率が業界平均（3 割前後）を下回っている。
- 開業して間もなく、まだ知られていない。
- 予約件数が多い（プランを下げると手数料の単価が上がるサービスがある。あるサービスでは有料プランのディナー 50 円が、無料プランでは実質 215 円になる）。

**「まだやめないでください」と言う。そのほうが結果的に長く付き合える。**

## 9. 書き方の規範

サイト・見積書・メール・提案のすべてに適用する。

### 9.1 原則

1. **できないことを先に書く。** あとで揉めない。
2. **測っていない数字は書かない。** 表示速度も作業時間も返答の速さも、測ってから書く。
3. **根拠のある数字だけ引く。** 出典と時点を必ず添える（他社の金額には「各社が公開している料金ページ（2026 年 9 月時点）」）。
4. **他社名を書かない。** 比べるのは仕組み。
5. **都合の悪い行を消さない。** 負けている比較も出す。
6. **「無制限」「無料」と書いたら、境界も同じ場所に書く。**
7. **サイトに書いたことは契約書にも書く。**

### 9.2 言葉づかい

- 読み手は 50〜60 代の事業主。**専門用語を使ったら、その場で日本語にする。**
- 誇張しない。「必ず」「圧倒的」「劇的」を使わない。
- 迎合しない。やめるべきでないことは「やめないでください」と言う。
- 「制作事例は、まだ 1 件目です」と書く。**他社の事例を自分の実績のように見せない。**

### 9.3 認知負荷を下げる

文章を読むのは負荷が高い。
アイコン・図・表で減らす。
ただし**アイコンは状態を示すとき（警告・禁止）だけ**に付ける。
飾りで付けない。

Vercel。
顧客に作り方を教えて、**顧客名義のアカウント**に載せる。

## 11. お金の算数

### 11.1 目標

2 人体制で月商 300 万円以上。

### 11.2 積み上げの構造

売上は 2 本。

- **制作**（フロー）：受注した月にだけ立つ。
- **運用**（ストック）：積み上がる。**ここが事業の本体。**

### 11.3 月商 300 万円に必要なもの

制作 4 件／月（平均単価 40 万円＝160 万円）とすると、残り 140 万円を運用で作る必要がある。
運用スタンダード 16,000 円なら **約 88 件のストック**。

月 4 件受注なら 22 か月で 88 件に届く。
**数の問題は時間が解く。問題は工数のほう。**

| 運用 1 件あたりの工数 | 88 件に必要な時間 | 2 人の月間可働 320 時間のうち |
|---|---|---|
| 3.5 時間（今のスタンダードの中身をそのままやる） | 308 時間 | **制作に回す時間が残らない** |
| 2.0 時間 | 176 時間 | 制作に 144 時間。4 件はぎりぎり |
| 1.5 時間 | 132 時間 | 制作に 188 時間。回る |

**結論：月商 300 万円の成否は、運用 1 件あたりの工数を何時間に抑えられるかで決まる。制作単価ではない。**

いま運用スタンダードに入れているのは、修正無制限＋マップ投稿月 4 回＋口コミ返信代行＋月次レポート＋検索エラー監視＋記事 3 か月に 1 本。
**これを 1.5 時間でやるには、テンプレート化と自動化が前提になる。**

### 11.4 ここに矛盾がある（直視する）

サイトには「人を増やして数をこなす形にはしません」と書いてある。
一方で月商 300 万円は 88 件の運用を前提とする。
**両立させる道は 3 つしかない。**

1. **運用の工数を落とす**（自動化・テンプレート化）。第一候補。10.5 の社内ツールがそのための投資。
2. **単価を上げる**（プロ 698,000 円・グロース 29,800 円の比率を上げる）。件数が減るので工数も減る。
3. **目標を下げる。**

**この 3 つのどれを取るかを決めていない。** 12.1 の最上位に置く。

### 11.5 赤字になりうる箇所

| | リスク |
|---|---|
| 運用ライト 5,800 円 | 修正無制限を付けている。**月 1〜2 件を超えると赤字。** 但し書きが要るかもしれない |
| シングル 39,800 円 | 原価は想定 1 人日。取材・原稿・撮影補正・GBP 紐付け・ソース納品を含むので、**実測してから維持を判断する** |
| 出張撮影 | 全国対応で交通費実費。遠方案件が重なると移動時間が丸ごと消える |

**最初の 3 件は必ず実働時間を記録する。** 想定と実測がずれたら値段を直す。

# 第 II 部　お客様にお渡しするもの

**この部分はそのままお客様に読んでいただけます。**
サイトと契約書に書いてあることと同じ内容です。

## A. 何を売っているか

ホームページを作り、その後の更新と運用をお引き受けします。
ふつうの制作会社と違うのは、**作ったものがお客様のものになる**という 1 点です。

いまのホームページは、土地でいえば借地に建てた家に近い形になっていることがあります。
月額を払っているあいだは建っていますが、やめた日に更地にして返すことになります。
**紬がお渡しするのは、土地ごとお客様のものになるホームページです。**

具体的には、次の 4 つが手元に残ります。

| | 中身 | 確かめ方 |
|---|---|---|
| ① 住所 | ドメイン | 公開の登録簿で、お客様のお名前を確認できます |
| ② 建物 | ソースコード一式 | 契約書に納品物として書きます |
| ③ 地盤 | 置き場所 | どのサーバーにも置ける形で作ります |
| ④ 家具 | 写真と原稿の元データ | 用途の制限を付けません |

**業種によって値段は変えません。** 変わるのはページ数と、作るページの中身です。

## I. いまのサイトが借地かどうか、確かめる 6 つの質問

いまお使いのサイトについて、制作会社に聞いてみてください。
聞きにくければ、代わりにお聞きします。

1. ドメインの契約者名は、どなたの名前になっていますか。
2. 解約したら、いまのページはどうなりますか。
3. ソースコードは、もらえますか。
4. サイトの写真の元データは、手元にありますか。
5. 別の会社に引き継ぐとき、いくらかかりますか。
6. **「譲渡」されたあと、別の会社に引き継げますか。**

6 番がいちばん大事です。
「◯か月で無償譲渡」と書いてある場合、渡されるものに 2 種類あります。
**ソースコード一式（建物ごと）**なら、どのサーバーにも置けます。
**サイト作成ツールのアカウント（借地権だけ）**なら、そのツールの外へは持ち出せず、以後もそのツールに毎月払い続けることになります。
どちらも嘘ではないので、聞かないと分かりません。

**6 つとも「わからない」で構いません。** いちばん多いお答えです。
契約書をお持ちいただければ、一緒に読みます。無料です。
読んだ結果「いまのままで問題ありません」になることもあります。そのときは、そう申し上げます。
