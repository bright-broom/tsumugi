# 第 I 部　社内の運営規範

## 1. この事業は何か

### 1.1 定義

小規模事業者に対して、**その事業者が所有権を持てるホームページ**を制作し、その後の運用を引き受ける事業。
2名での運営を想定してきたが、本計画では本人の月140時間だけを契約可能容量の基礎とする。
地域は限定せず全国。
打ち合わせ・取材・修正はオンラインと電話で完結し、出張するのは撮影のときだけ。

### 1.2 対象の仮説（顧客層は未定）

| | |
|---|---|
| 業種 | 飲食店／工務店・建設／美容室・サロン／士業・専門事務所 |
| 規模 | 従業者 5 人以下を中心とする小規模事業者 |
| 状態 | ホームページを持っていない、またはポータルサイト・SNS だけで済ませている |

従業者 5 人以下のホームページ開設率は約 30% で、全体の 48.2% を大きく下回る。
業種別でも卸売・建設・不動産が約 30% で最低。
**市場は「まだ持っていない人」の側にある。**
（出典：Wepage 2025 年 7 月調査・n=3,000）

### 1.3 やらない事業

- 人を増やして件数をこなす形にはしない。
- 効果の根拠がないものを商品にしない（第 7 章）。
- 名指しで他社を叩く商売はしない。比べるのは仕組みであって会社ではない。

## 2. 主張の軸

### 2.1 一番の主張

> いまのホームページ制作会社が作るサイトは、土地でいえば**借地権**にあたる。
> 紬が作るのは、お客様が**所有権**を持てるホームページ。

この 1 文がすべての起点。
料金も、仕様も、契約書も、断る基準も、ここから導かれる。
**この主張を崩す判断は、どれだけ儲かってもしない。**

### 2.2 「所有」の定義

気分の話にしないため、4 つに分解し、それぞれ確かめられる形にしてある。

| | 中身 | 確かめ方 |
|---|---|---|
| ① 住所 | ドメイン | 公開の登録簿でお客様の名義を確認できる |
| ② 建物 | ソースコード一式 | 契約書に納品物として明記。GitHub に閲覧権限で招待 |
| ③ 地盤 | 置き場所 | 実行時 JavaScript 0 バイトなので、どのサーバーにも置ける |
| ④ 家具 | 写真・原稿の元データ | 用途の制限を付けずに渡す |

**③ が技術の話に見えて、実は営業上いちばん効く。**
サイト作成ツールで作られたページは書き出せる形になっていないため、「譲渡」されてもツールの外へ持ち出せない。
紬は HTML と CSS のまま渡すので、置き場所を選ばない。

### 2.3 喩えを弱めることで強くする

**本物の借地のほうが、いまのホームページ契約より守られている。**
ここを正直に書くことで、残りが信用される。

| | 契約の更新 | 終わったときに残るもの |
|---|---|---|
| 普通借地権 | 地主は正当な事由がなければ拒めない（借地借家法 6 条） | 建物を時価で買い取らせられる（同 13 条） |
| 定期借地権 | 更新なし（同 22〜24 条） | 買取請求できない。更地にして返す |
| 月額制のホームページ | 契約書しだい | 買取の規定がないことが多い。公開が止まる |

**必ず添える但し書き**：当方は弁護士ではない。
条文は仕組みを説明するための引用であり、個別契約の効力を判断するものではない。
実際の条件は契約書で確認していただく。

### 2.4 主張を技術的に支える不変条件

以下が崩れると、②③ の根拠が同時に消える。
**変更する前に必ず検査を通す。**

| 不変条件 | 現状 | 崩れると何が起きるか |
|---|---|---|
| 実行時 JavaScript 0 バイト | 全 21 ページで 0 件 | 「どのサーバーにも置ける」が言えなくなる |
| 表示速度 2.5 秒以内 | 実測 0.18 秒 | 納品条件を満たさない |
| 自動検査 608 項目 PASS | 0 FAIL | 「1 つでも落ちたら納品しない」が嘘になる |
| ドメインはお客様名義 | 運用ルール | ① が消える |

ページに `export const config = { unstable_runtimeJS: false }` を置き忘れるか、App Router に移すと、実行時 JavaScript が載る（置き忘れはビルドが止まる）。
**変更したら必ず `npm run build && npm run verify` を通すこと。**

## 3. 値付けの規範（2026-09-14改定）

| 商品 | 税別価格 | 向く依頼 | 提供範囲と境界 | 総作業時間の採算目標 |
|---|---:|---|---|---:|
| 入口をつくる | 79,800円 | 名刺・紹介・SNSからの受け皿 | 1ページ、既存の構成から選択、30分聞き取り、支給素材から原稿整理、既存予約先・連絡先への導線、確認1回 | 5.5時間 |
| 事業の土台をつくる | 198,000円 | サービス・料金・信頼情報をまとめる | 最大6ページ、60分聞き取り、原稿整理、問い合わせ導線、確認2回 | 15時間 |
| 情報を育てる | 398,000円 | 継続的にお知らせ・事例を追加する | 最大9ページ、更新管理・記事/事例の標準テンプレート、初期登録3件、操作説明、確認2回 | 26時間 |

共通：スマートフォン対応、顧客名義のドメイン・契約先、合意した検証条件、ソースと利用可能な原稿・画像の納品。第三者のフォント・素材・サービスはそれぞれの利用条件を明示する。

「ページ」は通常の公開コンテンツ単位。法務・プライバシー等の定型ページは別枠で明示し、顧客の承認済み原稿を掲載する。独自の法務原稿作成、取材記事、撮影、多言語、絞り込み、予約エンジン、EC・決済、会員機能、複雑なデータ移行は別見積もり。

修正回数は顧客側でまとめた確認ラウンド。合意した仕様に対する紬の不具合修正は回数に数えない。追加要望は着手前に内容・金額・納期を合意する。期限が来たことだけを理由に未承認の成果物を検収済みにしない。

**情報を育てるプランは、CMS・記事/事例テンプレートが検証できるまで受付開始しない。** 保守・フォーム等も、手動または外部サービスで提供条件を満たすことを確認してから売る。未実装の自動化を前提に納期や工数を約束しない。

1. **使わない月の固定費を減らせる。** 支援は任意。月単位で変更・終了でき、前月末までの申し出を翌月から適用する。追加のサイト買い取り代は取らない。外部サービスの更新費は残る。
2. **小さく始めた分を無駄にしない。** 同一事業・同じ構成資産を使う増築は、納品から12か月以内なら支払済みの制作本体額を1回だけ次のプランへ全額充当する。撮影・外部実費・運用費は対象外。全面再設計や別ブランドは別見積もり。差額以上の作業になる場合は安易に約束せず、先に範囲を整える。
3. **所有と支援を切り離す。** 解約だけを理由にサイトを削除しない。顧客名義のアカウント・データ・操作資料を渡す。通常の権限引継ぎを納品に含め、別環境での改修作業とは区別する。
4. **変更の総額を先に確定する。** 個別の承認なしに追加課金しない。高いプランに誘導する前に、依頼量を下げる・次月へ回す・自社で対応する選択肢を提示する。
5. **改善の採算を契約前に計算する。** 費用削減、追加受注の限界利益、実際に別の生産活動に振り向けられる時間を別々に確認する。同じ効果を二重計上しない。

これは無条件の成果返金や最安値保証ではない。制御できる納品・料金・引継ぎ条件で顧客の損失を減らす。

外部費は**月3,500円の仮置き**。Vercel Pro・ドメイン・従量分等の概算枠であり、見積時には通貨、座席、税、フォーム/CMSの有料枠を確認して置き換える。VercelのHobbyは非商用向けであり、事業サイトを無料運用する前提は置かない。[Hobbyの利用範囲](https://vercel.com/docs/plans/hobby)、[Proの公式料金](https://vercel.com/pricing)（2026-09-14確認、Proは月20米ドル〜。追加座席・従量等を別途確認）

| ページ規模 | 紬の制作＋外部費 / 36か月（保守契約なし） | 比較先の公開料金 / 36か月 | 紬−比較先 |
|---|---:|---:|---:|
| 1ページ | 205,800円 | 357,800円 | −152,000円 |
| 6ページ | 324,000円 | 537,800円 | −213,800円 |
| 9ページ / 比較先7〜12ページ | 524,000円 | 717,800円 | −193,800円 |

**同じ役務を安く売っているという比較ではない。** 比較先には月5回の変更を含み、紬は保守・更新をご自身で行うプラン。月5回更新したい顧客に、この表で割安だと言わない。比較先のドメイン・サーバー管理は掲載月額に含まれるが、個別オプションは見積もりで追加する。36か月を超えると比較先の譲渡・契約継続の選択があるため、その後の固定月額を一律に外挿しない。

6ページで紬の「整える」を選ぶ場合、同じ外部費仮定で36か月676,800円となり、比較先より139,000円高い。所有・作業の中身・費用差を並べ、価値がない相手には提案しない。1ページの制作費は79,800円。保守なしなら紬への月額は0円で、外部費を含む36か月の参考総額は205,800円。任意で「守る」を追加する場合は346,200円となる。

改善案件は、売上額ではなく「追加1件が生む限界利益」で判断する。例えば制作198,000円を24か月で按分し、整える9,800円＋外部費3,500円なら月21,550円。追加1件の限界利益が10,000円なら、月3件が単純回収の目安。これは目標の計算であって、問い合わせや受注の予測ではない。既存の費用が確実に削減できる場合はそれを差し引く。

## 4. 営業

### 4.1 リストの作り方

Google Places API で対象エリアを総ざらいし、ホームページ未保有／ポータル依存の店を抽出する。
スクリプトは `leadfinder`。

| | |
|---|---|
| 抽出 | `websiteUri` が空＝なし／食べログ・Instagram・ホットペッパー・LINE のみ＝ポータル依存。**両方を対象にする** |
| 優先度 | 口コミ数 45 ＋ 評価 20 ＋ 電話番号 20 ＋ サイト状態 15（0-100） |
| エリア基準 | 人口 10〜30 万の地方中核市／県庁所在地を外す（制作会社が薄い）／建設・卸売・不動産の比率が高い／従業者 5 人以下が多い |

**規約上の制約（必ず守る）**：Places API のコンテンツは恒久保存・DB 化が不可。
恒久保存できるのは `place_id` のみで、その他は 30 日以内に破棄する。
運用は「自社台帳には `place_id` と自分でヒアリングした内容だけを残し、Excel は 30 日サイクルで再生成して使い捨てる」。
商談に入った先は、自前で確認した情報として別管理へ移す。

優先度スコアは受注実績ではなく仮説。
**商談を 10 件回したら、配点を実績で調整する。**

### 4.2 初回接触で聞く 3 つ

1. いまホームページはありますか。
2. いま掲載費や広告費をいくら払っていますか（おおよそで可。請求書があれば見ながらのほうが早い）。
3. いちばん困っていることは何ですか。

この 3 つで、**その場で概算を出す。**

### 4.3 商談の順番

新しい予算をつくる前に、いま出ている費用を見る。
**これが紬の商談の型。**

1. 3 つの数字を聞く（掲載料／手数料／そのサイト経由の月間新規数）。
2. 新規 1 人あたりの獲得コストを一緒に計算する。**多くの店主がこの数字を見るのは初めて。ここだけでも意味がある。**
3. そのお客様の粗利と比べる。1 人 5,000 円かけて獲得した客の粗利が 3,000 円なら、そのプランは合っていない。
4. 3〜6 か月の併走計画を作る。**いきなりポータルをやめない。**
5. 契約の更新月に合わせてプランを下げる。「いますぐ安くなります」とは言わない。

送客手数料はディナー 1 人 220 円・ランチ 110 円（税込）で、**新規と常連を区別しない。**
いつも来てくださる方がネット予約するたびに 220 円かかる。

「整える」＋外部費概算は税込月14,630円。送客手数料が税込220円なら月67人分が単純比較の目安。制作費・予約先の追加費・掲載変更による集客への影響は別で、削減の保証ではない。
毎晩 4 名 ×30 日＝月 120 人の店なら、送客手数料だけで月 26,400 円払っていることになる。

### 4.4 業種ごとの財源

| 業種 | どこから出すか |
|---|---|
| 飲食店 | 食べログ。**ベーシック（税込 27,500 円）を無料プランに戻しても、ネット予約は固定費 0 円で使える**（手数料の単価は有料プランと同じ。同社が公式に明記）。予約を失わずに掲載料だけゼロにできる |
| 美容室 | ホットペッパービューティー。**掲載料は非公開なので推測で金額を言わない。直近の請求書を見せてもらう。** 無料プランは存在せず、予約売上の 2% が手数料 |
| 工務店・士業 | 広告費。止めるのではなく入札単価を下げる。商圏外への配信停止、成約ゼロの検索語の除外 |

**ライトプラン（11,000 円）と無料掲載の店には、この話は使えない。**
1 段下げても 11,000 円で、「整える」＋外部費概算 税込14,630 円に届かない。
**店のプランを確認せずに「1 段下げれば出ます」と言うのは不誠実。最初に必ず聞く。**

### 4.5 広告について

「やめましょう」とは言わない。
止めた実測例では、自然検索の流入は一時的に増えたものの続かず、**予算 3.45 倍に対して売上は 1.07 倍**だった。
正解は止めることではなく入札単価を下げること。
別の事例では約 30% 下げながら検索結果上部にほぼ常時表示されている。

### 4.6 いまの実力を直視する

価格・所有条件だけで受注できるとは考えない。制作実績、集客経路、顧客の更新負担、外部費を含む総額を確かめる。6ページ＋「整える」＋外部費概算の36か月総額は676,800円で、参考料金より139,000円高い。効果を説明できない相手には提案しない。

### 5.3 納品条件

**20 項目すべてを満たすこと。1 つでも落ちたら納品しない。**
検証は機械で行う（`tools/verify/`／608 項目）。

区分は 4 つ。

| 区分 | 中身 | 根拠の性格 |
|---|---|---|
| 情報（6 項目） | 電話・営業時間・住所地図・料金・電話とフォームの主役・対応エリア | 調査で「連絡されない理由」の 1 位と 2 位 |
| 中身（5 項目） | 写真・顔写真・実績事例・お客様の声・解説記事 3〜5 本 | 見た人が判断材料にしているもの |
| 技術（6 項目） | スマホと PC で同内容・2.5 秒以内・遅延読み込みの設定・スコア満点は狙わない・44px のタップ領域・構造化データ | 数字で効果が確認できるものだけ |
| 運用（3 項目） | GBP リンクの正しい紐付け・通知 2 系統と返答時間・口コミの鮮度 | 作ったあとに効く部分 |

覚えておくべき数字：

## 7. 売らないもの・約束しないもの

### 7.1 売らないもの

根拠がないものは商品にしない。
**これらを売っている制作会社は実際にある。同じ商品棚に並ばないことが、いちばんの違い。**

| 売らないもの | 理由 |
|---|---|
| AI 検索対策（LLMO） | Google の公式ガイドが「生成 AI の検索に構造化データも AI 向けの書き方も不要」と明記している |
| 検索順位の保証 | Google が公表していない要因を保証できる者はいない |
| 記事の量産 | ページ数と引用されやすさの相関はほぼゼロ |
| 表示速度スコアの満点 | Google 自身が「SEO のために満点を狙うのは時間の使い方として最善ではない」と書いている |
| Google の飲食店カルーセル狙いの設定 | 限られた事業者にしか表示されない機能なので、狙っても意味がない |

### 7.2 約束しないもの

- 検索で 1 位になること。
- 新規のお客様が増えること（美容室の市場は前年比 5.9% 縮小）。
- 補助金の採択（採択率 47.2%）。

**確実にできるのは、手数料の削減と再来店の導線づくり。そこは数字で確認できる。**

### 7.3 断る基準

以下は受けない。

- 法令に反する内容、事実と異なる表示。
- 反社会的勢力に関係する場合。
- 掲載する情報（料金・資格・実績）が事実でない、他人の文章・写真を無断で使うことを求められる場合。
- 順位保証・集客保証を契約条件として求められる場合。
- **弁護士の広告規制に触れる表現を求められる場合**（日本弁護士連合会の会規で、誇大な広告・他の弁護士との比較・勝訴率の表示が禁止。顧問先の掲載には書面での同意が必要）。

### 7.4 「やめないでください」と言う基準

ポータル掲載の見直しは主力商品だが、**次のいずれかに当てはまる店には、やめるのは危険だと伝える。**

- 既存客の連絡先が整理されておらず、再来店の導線がない。
- 再来店率が業界平均（3 割前後）を下回っている。
- 開業して間もなく、まだ知られていない。
- 予約件数が多い（プランを下げると手数料の単価が上がるサービスがある。あるサービスでは有料プランのディナー 50 円が、無料プランでは実質 215 円になる）。

**「まだやめないでください」と言う。そのほうが結果的に長く付き合える。**

## 9. 書き方の規範

サイト・見積書・メール・提案のすべてに適用する。

### 9.1 原則

1. **できないことを先に書く。** あとで揉めない。
2. **測っていない数字は書かない。** 表示速度も作業時間も返答の速さも、測ってから書く。
3. **根拠のある数字だけ引く。** 出典と時点を必ず添える（他社の金額には「各社が公開している料金ページ（2026 年 9 月時点）」）。
4. **他社名を書かない。** 比べるのは仕組み。
5. **都合の悪い行を消さない。** 負けている比較も出す。
6. **「無制限」「無料」と書いたら、境界も同じ場所に書く。**
7. **サイトに書いたことは契約書にも書く。**

### 9.2 言葉づかい

- 読み手は 50〜60 代の事業主。**専門用語を使ったら、その場で日本語にする。**
- 誇張しない。「必ず」「圧倒的」「劇的」を使わない。
- 迎合しない。やめるべきでないことは「やめないでください」と言う。
- 「制作事例は、まだ 1 件目です」と書く。**他社の事例を自分の実績のように見せない。**

### 9.3 認知負荷を下げる

文章を読むのは負荷が高い。
アイコン・図・表で減らす。
ただし**アイコンは状態を示すとき（警告・禁止）だけ**に付ける。
飾りで付けない。

### 10.2 手順

```bash
cd ~/dev/tsumugi/site && npm run dev      # http://localhost:3000
cd ~/dev/tsumugi/site && npm run build    # → out/
cd ~/dev/tsumugi/site && npm run verify
```

WARN 1 は `PLACEHOLDER=true`（電話番号・住所が仮）。公開前に潰す既知の 1 件。

### 10.3 触るときの注意

- **金額を変えるときは `src/content/prices.ts` の 1 か所。** Excel を直してもサイトは変わらない。
- **`RUN` や `BUILD` を添字で引かない。** 必ず `run('run_standard')` のように key で引く。
  過去に運用プランを 1 つ足したとき、添字参照 11 か所が静かにずれ、**全ページの月額が 28,000 円 → 21,800 円に下振れしたまま検査が全部通った。**
  再発防止に検査 29「価格の一致」を置いてある。
- **全ページに `export const config = { unstable_runtimeJS: false }` が要る。** 忘れると実行時 JavaScript が載り、主張が崩れる（ビルドが止まる）。
- **CSS は `src/styles/` を直す。** `site/public/theme.css` は生成物。
- Next.js のメジャー更新は、顧客サイトを 1 件納品して基準が実戦で効くのを見てから。上げるときは検査を全部通す。

### 10.4 ホスティング

Vercel。
顧客に作り方を教えて、**顧客名義のアカウント**に載せる。

**`◯◯.vercel.app` をそのまま渡さない。**
全プランに「独自ドメイン取得（初日からお客様の名義）」と書いてあり、所有 4 要素の ① は「住所＝ドメイン」。
vercel.app は Vercel の持ち物なので、渡しているのは住所ではなく間借り。
`source.html` に載せた「Google が 2024 年に無料サイトを停止して URL が死んだ」例が、まさにこの形。
ドメインと商用ホスティングは顧客名義で契約し、実費は料金とは別に明示する。vercel.app は公開前の確認用に留める。

### 10.5 社内ツールは別スタック

サイトは Next.js の静的書き出し（Pages Router・実行時 JavaScript 0 バイト）。
**社内の道具は Next.js + TypeScript + Vercel。**
こちらは SSR も API も認証も要る本物のアプリなので、実行時 JavaScript の制約を持ち込まない。

作る予定のもの：leadfinder（営業リスト）／見積もり・総額シミュレータ／**修正指示ツール**（画面上で直したい箇所を指定する。競合が持っていて実際に効いている）／顧客管理・月次レポート生成／問い合わせフォームの受け口。

## 11. 月140時間の経営計画

以下は実績ではなく仮定。本人の時間単価5,000円、決済等3%、追加の固定費月50,000円。制作の現金獲得費は入口6,000円・土台10,000円・育成20,000円を置く。営業の本人時間は月28時間に含め、獲得費と二重計上しない。

| 商品 | 直接作業時間 | 外注・ツール等＋現金獲得費 | 時間原価・決済費控除後の貢献率 |
|---|---:|---:|---:|
| 入口79,800円 | 5.5時間 | 8,000円 | 52.5% |
| 土台198,000円 | 15時間 | 15,000円 | 51.5% |
| 情報育成398,000円 | 26時間 | 30,000円 | 56.8% |
| 守る3,900円 | 0.30時間 | 300円 | 50.8% |
| 整える9,800円 | 0.75時間 | 400円 | 54.7% |
| 育てる29,800円 | 2.25時間 | 700円 | 56.9% |

貢献率は会計上の営業利益率ではない。本人の営業・事務・予備時間と固定費は、次の全体計算で控除する。制作時間は聞き取り、原稿、調整、確認、修正、公開、引継ぎまでを含み、AIで作る時間だけを測らない。

**最低受注価格 =（直接時間×5,000円＋外注・ツール等＋現金獲得費）÷（1−決済率3%−目標貢献率50%）。**

土台の最低価格はこの仮定で191,490円。198,000円には余裕が大きくない。制作が20時間なら244,681円以上、現金獲得費が40,000円なら255,320円以上が必要。値段を据え置いて未来の運用契約で穴埋めしない。価格か範囲を修正する。

### 月140時間の配分

| 使い道 | 時間 |
|---|---:|
| 営業・経理・商品改善 | 28時間 |
| 突発対応・遅延の予備 | 28時間 |
| 契約に使える制作・支援 | **84時間** |

### 目指す一つの組合せ

月に土台1件・情報育成1件、支援32社（守る10・整える16・育てる6）の場合：

- 制作売上596,000円＋継続売上374,600円＝**月商970,600円**。
- 制作41時間＋支援28.5時間＝**69.5時間**。84時間の枠に対して14.5時間の余白。
- 外注・ツール・獲得・決済等の現金変動費87,718円と固定費50,000円を引くと、本人報酬を引く前の金額は832,882円。
- **月140時間すべてを5,000円＝700,000円で評価しても、132,882円が残る。** 未使用時間・営業時間・予備時間も含めて一度だけ差し引く。個人事業の確定利益や税引後手取りではなく、設備投資・税・借入返済前の計画上の余力。

月商約97万円は、32社が積み上がり398,000円のプランが販売可能になった後の条件付き目標で、来月の予測ではない。CMS未提供の間は、その売上を確定計画へ入れない。

**月商300万円は、84時間の納品枠に対し平均35,714円/時間が必要。** 現在案の商品の時間当たり売上を大きく上回る。少人数・140時間のままで狙うなら、顧客にとっての価値を実証した高単価の導入案件、再利用できる商品・ライセンスなど、収益構造を変える必要がある。保守件数を増やすだけの計画にはしない。

### 上振れ・解約・立ち上がりへの耐性

- 全案件の工数が25%増えると86.875時間になり、納品枠を2.875時間超える。追加受注を止め、作業範囲・納期を調整する。利益の計算だけが黒字でも受けない。
- 32社が月30分ずつ余分に使うだけで16時間増え、納品枠を1.5時間超える。無制限更新を復活させない。
- 新規制作2件/月、支援移行75%、解約2%/月、開始0社なら、32社到達はモデル上28か月目。解約5%なら収束値30社で32社へ届かない。失注や受注変動を無視した単純計算なので、実測の転換率で更新する。
- 支援0社で制作2件だけなら、上と同じ仮定で本人報酬前483,120円、本人時間70万円を差し引くと−216,880円。立ち上がりから報酬70万円を固定すると不足する。生活費・税・初期開発費を別途入れて必要資金を決める。

# 第 II 部　お客様にお渡しするもの

## A. 何を売っているか

ホームページを作り、その後の更新と運用をお引き受けします。
ふつうの制作会社と違うのは、**作ったものがお客様のものになる**という 1 点です。

いまのホームページは、土地でいえば借地に建てた家に近い形になっていることがあります。
月額を払っているあいだは建っていますが、やめた日に更地にして返すことになります。
**紬がお渡しするのは、土地ごとお客様のものになるホームページです。**

具体的には、次の 4 つが手元に残ります。

|---|---|---|

## B. 料金（すべて税別）

制作は入口をつくる79,800円、事業の土台をつくる198,000円、情報を育てる398,000円（受付準備中）。仕様は第3章の表をご確認ください。着手時50%・検収時50%です。自社24回分割の新規受付は行いません。

継続支援は任意です。自分で管理0円、守る3,900円/月、整える9,800円/月、育てる29,800円/月。守るには通常の変更作業は含みません。整えるは月30分、育てるは月90分の作業と30分の打合せです。撮影・外部サービスは別途見積もります。

増築時の制作費充当は同一事業・既存資産を再利用できる範囲・納品から12か月以内・1回に限ります。全面再設計や別ブランドは対象外です。

## C. 月額制との比較

外部費は**月3,500円の仮置き**。Vercel Pro・ドメイン・従量分等の概算枠であり、見積時には通貨、座席、税、フォーム/CMSの有料枠を確認して置き換える。VercelのHobbyは非商用向けであり、事業サイトを無料運用する前提は置かない。[Hobbyの利用範囲](https://vercel.com/docs/plans/hobby)、[Proの公式料金](https://vercel.com/pricing)（2026-09-14確認、Proは月20米ドル〜。追加座席・従量等を別途確認）

| ページ規模 | 紬の制作＋外部費 / 36か月（保守契約なし） | 比較先の公開料金 / 36か月 | 紬−比較先 |
|---|---:|---:|---:|
| 1ページ | 205,800円 | 357,800円 | −152,000円 |
| 6ページ | 324,000円 | 537,800円 | −213,800円 |
| 9ページ / 比較先7〜12ページ | 524,000円 | 717,800円 | −193,800円 |

**同じ役務を安く売っているという比較ではない。** 比較先には月5回の変更を含み、紬は保守・更新をご自身で行うプラン。月5回更新したい顧客に、この表で割安だと言わない。比較先のドメイン・サーバー管理は掲載月額に含まれるが、個別オプションは見積もりで追加する。36か月を超えると比較先の譲渡・契約継続の選択があるため、その後の固定月額を一律に外挿しない。

6ページで紬の「整える」を選ぶ場合、同じ外部費仮定で36か月676,800円となり、比較先より139,000円高い。所有・作業の中身・費用差を並べ、価値がない相手には提案しない。1ページの制作費は79,800円。保守なしなら紬への月額は0円で、外部費を含む36か月の参考総額は205,800円。任意で「守る」を追加する場合は346,200円となる。

改善案件は、売上額ではなく「追加1件が生む限界利益」で判断する。例えば制作198,000円を24か月で按分し、整える9,800円＋外部費3,500円なら月21,550円。追加1件の限界利益が10,000円なら、月3件が単純回収の目安。これは目標の計算であって、問い合わせや受注の予測ではない。既存の費用が確実に削減できる場合はそれを差し引く。

## I. いまのサイトが借地かどうか、確かめる 6 つの質問

いまお使いのサイトについて、制作会社に聞いてみてください。

1. ドメインの契約者名は、どなたの名前になっていますか。

4. サイトの写真の元データは、手元にありますか。
5. 別の会社に引き継ぐとき、いくらかかりますか。
6. **「譲渡」されたあと、別の会社に引き継げますか。**

6 番がいちばん大事です。
「◯か月で無償譲渡」と書いてある場合、渡されるものに 2 種類あります。
**ソースコード一式（建物ごと）**なら、どのサーバーにも置けます。

どちらも嘘ではないので、聞かないと分かりません。

**6 つとも「わからない」で構いません。** いちばん多いお答えです。
