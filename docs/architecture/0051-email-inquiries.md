# 0051 自社サイトの問い合わせをメールで受け付ける

- 採用日：2026-09-16
- ユーザー指定：`leonardodavinci.works@gmail.com` を掲載し、フォームを開かない仕様にする。

連絡先は i18n の共通設定に置き、問い合わせ・フッター・法定表示・プライバシーの表示に反映する。`CONTACT_METHOD=email` を自社サイトの設定にし、問い合わせページでは入力フォームと未設定の送信ボタンを表示しない。メールリンクは `mailto:` でメールアプリへ渡す。ページ内・固定バーの相談 CTA もメールへ直接つなぎ、電話窓口は維持する。アドレスをコピーして別のメールサービスで使うこともできる。

顧客テンプレート向けのフォームと受付サービスは残し、明示的に `CONTACT_METHOD=form` に切り替えたときだけ使用する。公開条件の検査も選択した窓口に合わせ、メール受付では有効なメールアドレス、フォーム受付では有効な送信先を要求する。メールの受信実績は設定だけでは確認できないため、受信済み・試験済みとは記録しない。

共通デザインガイドの既存部品優先に従い、現行のリンクと中央管理 CSS を使用。長いアドレスは狭い画面で折り返す。追加パッケージや実行時 JavaScript は不要。既存のフォーム連携テストはフォームモードを明示し、メールモードの公開条件・フォーム非表示を追加検査する。

検証結果：Node 24.21.0 / npm 12.0.2、check・lint・Vitest 479 件・料金モデル 12 件・build 成功。全項目 PASS 572 / WARN 1 / FAIL 0、静的 PASS 318 / WARN 1 / FAIL 0。フォーム非表示でラベル対応の対象が 1 件減少。Chromium・JavaScript 無効・幅 1440 / 320 px でメールリンクの文字列・宛先、フォーム非表示、横はみ出しなしを確認。21 ページの実行時 JS は 0。メール送信・受信試験は行っていない。
