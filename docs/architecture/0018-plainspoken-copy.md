# ADR 0018: 説明を具体的な仕事内容に揃える

- 状態: 採用
- 日付: 2026-09-14

## 判断

「AIっぽい部分を更新する」という依頼に対し、全21ページの文言・図解ラベル・共有画像・共通UIを確認した。AIが書いたかを判定するのではなく、読者にとって不自然な次の特徴を修正対象にした。

- 「正直に書きます」「まともな仕事」「手加減しない」など、読み手が判断するはずの自己評価。
- 他社や月額制全般を一括りにする比較、結果や移転を無条件で言い切る説明。
- 他分野の調査数字から、その店に必要な制作内容を即断する文章。
- 顧客向けページに混ざった設定ファイル名、担当者向けの執筆指示、サービス準備中の曖昧な表示。
- 手順ではない章にも連番を付けるホームの装飾。

「何を頼めるか」「何を受け取るか」「どんな条件があるか」が分かる言葉に改めた。架空の顧客の声や担当者の経歴、効果の実績は追加していない。

## 対象と境界

本文はi18nの正本を更新し、前のADRで共通化したFAQ・所有の4項目・ナビゲーションを維持する。FAQは30問、仕様は20項目のまま。所有ページの確認項目は実際には6件あったため、見出しの「5つ」を「6つ」に修正した。

業種別の掲載内容、標準仕様、担当者紹介、広告の説明は、一般的な数値による説得から具体的な作業の説明へ変更する。出典の見直しや市場調査の更新は今回実施していない。比較の金額と不利な行、採択条件、受付準備中の表示、権利と外部費の条件は残す。料金モデル・契約・プライバシー・法定表記の本文は変更しない。

国生みの暫定画像と画像内のブランドコピーは、承認済みの素材として維持する。アイボリー・エスプレッソ・琥珀の3色、ホームの4図解、既存のLucideアイコンも維持。装飾の章番号とその余白を取り除き、見出しを本文の左端に揃える。制作や申請の手順を示す番号は残す。

共有カードは、ホーム・料金・仕様・補助金・実績の5枚を本文に合わせて更新。従来と同じMacの生成環境を使い、それ以外の画像は差分がないことを確認する。追加のライブラリや実行時JavaScriptはない。共通frontend-designガイドの既存部品・トークンを再利用する方針に沿う。

## 検証

型・依存・文言・未使用コードの検査、lint、既存の単体113件、料金モデル9件、ビルドを確認。標準検査603 PASS / WARN 1 / FAIL 0、静的検査358 PASS / WARN 1 / FAIL 0。既知の仮設定以外に警告はない。公開21ページの実行時JavaScriptは0。

Chromiumで21ページ×1440/390/320pxの63組を確認。本文の折りたたみとメニューを開き、コントラスト、横はみ出し、アンカー、ID重複に失敗がないことを確認した。ホーム導入・FAQ・フッターと共有画像を目視し、文章を組み立てたあとのつながりも確認した。

全ページのLucideアイコン数は変更前と一致。契約・プライバシー・法定表記のmain内部は完全一致。HTML/CSS以外の23ファイルは同一で、差分は意図した共有カード5枚のみ。本番へのマージ・本番デプロイ、実機Safariの検証は今回の範囲外。
