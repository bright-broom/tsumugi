# ADR 0016: 琥珀と調和するメイン・サブカラー

- 状態: 採用
- 日付: 2026-09-14
- 更新対象: ADR 0014・0015のメイン／サブの色値

## 判断

利用者の「メインとサブカラーも相性のいい色へ」という希望に合わせ、メインをアイボリー `#FFF8ED`、サブをエスプレッソブラウン `#302820` に変更する。アクセントの琥珀 `#FFB000` を保持し、3色を暖色側へ揃える。明るい背景のやわらかさと、濃い文字・セクションの落ち着きを両立する意図で選ぶ。

イラストを除くUI面積70/20/10の目安、部品の寸法・構成・文言・価格・ルート・図解・アイコン・ヒーロー原画を維持する。ブラウザテーマ色、線や補助文字、反転表示、OGP21枚、ファビコン3種は中央トークンから同期する。CSSの追加色や追加依存はない。OGPはADR 0014・0015と同じmacOSの既存フォント環境で生成する。

## 検証

型・lint・単体107件・料金モデル9件・ビルドを実施。標準603 PASS / WARN 1 / FAIL 0、静的358 PASS。既知の仮設定警告は維持する。PCとスマートフォンのホームを目視し、本文、料金パネル、濃い比較セクション、相談を確認した。全21ページ×390/1440pxの文字・図のコントラストと横はみ出しを42組で検査し、失敗なしを確認した。

検証環境はChromium。色の好みや成果には利用者ごとの差があり、売上効果を実証した変更ではない。本番デプロイ・実機Safariは今回の範囲外。
