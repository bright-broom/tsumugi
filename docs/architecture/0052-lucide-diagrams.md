# 0052 図解を Lucide の線画と共通の表示部品で統一する

- 採用日：2026-09-17
- 対象：所有の比較、集客経路、月額費用、契約期間、補助金の内訳、申請手順の 6 種類。TOP・料金・所有・掲載費・補助金の 5 ページ、9 箇所に適用。

## 表示の方針

文章だけの箱を、内容に対応する線画アイコン・名称・補足の順に整理する。所有と集客は共通の `DiagramNode`、費用と補助金は `MetricBand` にまとめる。色は既存のアイボリー・エスプレッソ・琥珀のまま、通常の面は薄い輪郭、紬側や補助金・差額はアクセントで示す。装飾目的の連番・グラデーション・アニメーションは追加しない。

帯グラフは各金額の割合で幅を計算し、文字をバーの中から独立した説明欄へ移す。小さな割合でも金額が読めるようにし、表示上の最小幅で比率を変えない。従来のバー間の余白による差し引きもなくし、割合どおりの連続したバーにする。PC は横方向、狭い画面は縦方向に組み直す既存の SVG キャンバスを維持する。

掲載費の図の見出しは「掲載料（月額）」とし、そこで使われていた固有サービス名を外す。他の箇所の匿名化は既存の Issue #62 に残る。金額の入力元、比較期間、支援・外部費や採択の条件は変えない。表示文言は引き続き i18n から受け取る。

## 採用元と構成

共通 frontend-design ガイドと CATALOG の I01 に従い、導入済みの **lucide-react 1.45.0**（[公式](https://lucide.dev/)、ISC）を使用。`package.json` とインストール済みパッケージを確認した。新しい依存は追加しない。地球・鍵・利用者・店舗・書類・カメラ・時計・握手など、意味に対応する既存のアイコンだけを使用する。

`Figure` が必要なアイコンを SVG `symbol` として 1 回定義し、`DiagramIcon` が `use` で参照する。PC とモバイルで図形データを重複させない。ID は Figure ごとの `useId` から作り、同じ図が複数ある場合も衝突しない。アイコンは装飾として読み上げ対象から外し、外側の図の説明とキャプションを保つ。外部リクエストと実行時 JavaScript の追加はない。

面・バー・文字の既定値はグローバル Tailwind CSS に集約。SVG には座標・数値比率・用途によるサイズを残す。
