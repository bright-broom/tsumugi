# 0050 制作のみ・保守契約なしを基本の料金表示にする

- 採用日：2026-09-16
- 根拠：ユーザーが「保守費なしでもプランがあるので 79,800 円のみ」と基本案内を指定。
- ADR 0049 の任意保守 月 3,900 円は維持。保守の加入を制作の条件にしない。

## 表示と計算

TOP の主価格は「紬・1 ページの制作費（買い切り）79,800 円」。紬への月額は 0 円で、管理を依頼する人だけ支援プランを追加する。共有の制作カード・各ページの入口案内・料金ページも同じ説明にする。文言は i18n、金額は `src/content/prices.ts` から渡す。

ドメイン・サーバー等は顧客の直接契約で実費がかかるため、79,800 円を公開維持の総額とは表示しない。月額制の参考総額には期間、紬の主価格には制作費と明示し、差額は外部費込みの同じ期間で計算する。月 3,500 円の外部費仮定では、36 か月の総額は 1 ページ 205,800 円、6 ページ 324,000 円、9 ページ 524,000 円。参考料金との差はそれぞれ −152,000 円、−213,800 円、−193,800 円となる。

保守・更新を自分で行う条件を併記し、更新込みの参考先と同じ役務として扱わない。「整える」を選ぶ 6 ページの例は引き続き 676,800 円・参考先より 139,000 円高い。任意支援の価格・作業範囲・採算モデルは変えない。

## 実装と資料

公開比較の `compareRows()` は `run_self`、社内試算の省略時は `self` を選ぶ。明示的に支援を選んだ計算は維持する。事業規範・料金設計・説明方針を更新し、Excel の 2 比較シートでは月額支援の参照先を「自分で管理」の入力に変更する。保守 3,900 円の入力自体は残す。新規ライブラリ・レイアウト方式の追加はない。

## 検証

主価格と期間総額の区別、保守なしの既定値、任意保守の残存、差額の正負・同額をテストする。Excel は LibreOffice の再計算結果だけを元の数式セルに戻し、全 113 数式にエラー・未評価なし、表示書式の変更なし、比較総額と差額がサイトと一致することを確認した。

Node 24.21.0 / npm 12.0.2 で validate と全項目 verify が成功。Vitest 477 件・料金モデル 12 件、静的 PASS 319 / WARN 1 / FAIL 0、全項目 PASS 573 / WARN 1 / FAIL 0（対象なし 40）。WARN は既存の本番公開条件の未設定。公開 21 ページの実行時 JavaScript は 0。Chromium・JavaScript 無効・幅 1440 / 390 / 320 px で主価格が 79,800 円であること、期間総額・差額・月額 0 円の表示と横はみ出しなしを確認した。実機 Safari・本番公開は未確認。
