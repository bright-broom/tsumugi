# 0029 ヒーローのコピーをすべての幅で絵の中に収める

- 日付：2026-09-16
- 状態：採用（Issue #60）。ADR 0019 の「768px 以下は画像の下に置く」を置き換える

## 問題

`responsive.css` はコピーを通常は文書の流れに置き、769px 以上だけ絶対配置で絵に重ねていた。768px 以下では絵（390px 幅で高さ 228px）の下に、コピーのための茶色い帯（高さ 206px）ができていた。769px を境に文字の書体・大きさ・位置が跳んでいた。

## 判断

- **区画の高さを「絵の比率」と「コピーの高さ」の大きいほうにする。** `.brand-hero` を 1 マスのグリッドにし、`::before` が高さ `max(22rem, 100cqw × 958 / 1641)` を持ち、コピーも同じマスに重ねる。コピーのほうが高くなれば区画が伸びるので、固定の高さで文字を切らない。
- **絵は区画いっぱいに `object-fit: cover` で敷く。** 区画の高さが絵の比率より高くなる狭い画面（約 603px 未満）では左右を切る。`object-position: 78% 50%` で右寄りの二柱を残す。絵の下に帯は作らない。
- `aspect-ratio` と `min-height` を併用すると、最小の高さが比率で最小の幅に換算され、600px 以下で区画が 603px に広がって横スクロールが出た。幅（`cqw`）から高さを計算する形にして避けた。
- **文字の大きさ・幅・余白は区画の幅に連動させ、ブレークポイントを持たない。**
  - 見出し `max(--text-hero-mb, 6.4cqw)`、本文 `max(--text-body, 2.15cqw)`。769px 以上は従来の値（6.4cqw / 2.15cqw）と同じ。
  - 左の余白 `max(20px, 5cqw)`、幅 `min(区画幅 − 左右の余白, max(55cqw, 26rem))`。PC は従来どおり絵の幅の 55%。
  - 書体は全幅で明朝（`font-brand`）。上下は区画の中央に置く。従来の PC の位置（上から 26%）とほぼ同じになる。
  - 本文は `word-break: auto-phrase` で文節で折り返す。
- **判読性は陰影で確保する。** 左からエスプレッソを 58% → 34%（55% の位置）→ 透明（80%）に薄くするグラデーションと、文字の影を重ねる。色はトークンの `--color-ink` から `color-mix` で作り、新しい色は足さない。顔との重なりは Issue の指示どおり許容する。
- 文字は画像に焼き込まず、HTML とカタログのまま（ADR 0019・0030）。背景の SVG はバイト単位で変わらない。
