# 0010 — 料金の再設計を、公開価格と分けて検証する

日付：2026-09-14。状態：判断用モデルの分離を採用。新料金のプロジェクトへの採用は [ADR 0011](0011-adopt-pricing-140h.md) で決定。

## 背景

料金の再設計と、本人が使える時間が月140時間であることが指定された。顧客層と実作業時間は未確定。公開中の料金には無制限更新、撮影、分割払いが絡み、金額だけを変更すると提供条件が食い違う。

## 決定

`tools/pricing/` に、価格・工数・獲得費・外部費・解約率を入力にした独立の判断モデルを置く。公開サイトからは読み込まない。追加依存なしのNode.js標準機能で、受注可能時間、個別採算、本人時間を含めた月次収支、顧客総額を再計算する。

本人の時間は、個別商品の貢献率では直接時間に、月次全体では月140時間すべてに一度だけ計上する。時間が上限を超えたケースは、計算上の収支が黒字でも実行可能とは判定しない。

公開価格の正本は `site/src/content/prices.ts` に保つ。提案の採用時は公開カタログ・契約・比較・図・ビジネスガイドラインを一緒に変更し、未実装機能を販売可能なものとして表示しない。公開サイトの実行時JS 0バイトは維持する。

## 検証

モデルのテストは、工数超過、現金獲得費の増加、本人時間の二重計上、不利な比較、最低契約期間、顧客数の到達不能を含む。提案価格で利益が出るテストだけにしない。

経営上の根拠と条件は [料金再設計](../business/pricing-redesign-140h.md) を参照。
