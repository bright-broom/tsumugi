# 0035 — 受付サービスの配備先・保存先・通知手段の候補（オーナー判断）

日付：2026-09-16。状態：**提案（未決）**。関連：[#10](https://github.com/bright-broom/tsumugi/issues/10)、[#11](https://github.com/bright-broom/tsumugi/issues/11)、[#33](https://github.com/bright-broom/tsumugi/issues/33)、[0032](0032-inquiry-intake-service.md)。

## この記録の位置づけ

受付サービスは保存先・送信アダプタ・レート制限をインターフェースにしてあり（[0032](0032-inquiry-intake-service.md)）、どの配備先にも載せられる。どれを使うかは費用・規約・名義に関わるため、ここでは候補と判断材料だけを残し、決定はオーナーに委ねる。

**無料枠の数値・料金は記載しない。** この作業では公式ページを確認していないため、採用を検討する時点で各社の公式の料金・規約ページを確認し、確認日と一緒にこの記録へ追記する。

## 必要な条件

| 条件 | 理由 |
|---|---|
| 同じ内容の判定と保存を原子的に行える（一意制約・トランザクション・条件付き書き込み） | 重複送信を同じ受付番号に寄せる。`createOrGetRecent` |
| 読み取りから書き込みまでを比較して更新できる | 通知の二重送信を防ぐ貸出。`update` |
| 記録を確実に削除でき、削除の対象を一覧できる | 保持期限と削除のお求め |
| アクセスできる人を 2 名に絞れ、操作の記録を残せる | プライバシー表示 |
| 無料枠を超えたときに、課金されずに止まるか、上限を設定できる | 有料費用を発生させない |
| 事業での利用が規約で認められている | 自社・顧客の商用サイト |
| データの所在地・バックアップ・保持期間が分かる | プライバシー表示との整合 |
| 顧客サイトのテンプレートとして、顧客名義のアカウントでも同じ手順で作れる | 所有の方針 |

## 候補

| 構成 | 合う点 | 注意する点 |
|---|---|---|
| Cloudflare Workers ＋ D1（SQLite） | ハンドラの形（`fetch`・`waitUntil`・Cron Trigger）がそのまま合う。SQL の一意制約とトランザクションで原子性を満たせる | 無料枠・商用利用の条件を確認する。静的サイトを別のホスティングに置く場合は Origin の許可リストを設定する |
| Cloudflare Workers ＋ KV | 設定が少ない | 結果整合で、重複判定と貸出の原子性を満たしにくい。**保存先には不向き**（レート制限の保存先には使える） |
| Vercel Functions ＋ マーケットプレイスの Postgres / Redis | 既存の Vercel 連携を使える | このリポジトリには `api/` を置けない（静的サイトと一緒に配備される）ため別プロジェクトにする。Hobby は非商用向け（[operations.md](../operations.md)）。連携先ごとに無料枠と停止条件を確認する |
| 任意の Node サーバー ＋ SQLite / Postgres | 事業者の制約が少ない | サーバーの保守・監視・バックアップを自分で持つ。月額費用が発生しやすい |
| 外部のフォーム受付サービス | 実装が不要 | 重複の寄せ・返信期限・2 名への限定・期限での削除を自前で担保できない。プライバシー表示の「委託」に当たる |

暫定の第一候補は Cloudflare Workers ＋ D1（ハンドラの形との一致と原子性のため）。ただし無料枠・超過時の挙動・商用利用の規約を確認するまでは決定しない。

## 通知の手段

| 手段 | 注意する点 |
|---|---|
| メール送信 | 担当者宛てだけに送るので、宛先を事前に登録する方式の送信機能でも足りる可能性がある。送信事業者の無料枠・送信ドメインの認証（SPF・DKIM）を確認する |
| LINE（公式アカウントのメッセージ送信） | 無料で送れる通数はプランによる。担当者を友だちに登録する手順が要る |
| SMS | 一般に 1 通ごとに費用がかかる。無料の範囲で運用するなら LINE を先に検討する |

いずれも実際の送信・契約はまだ行わない。採用後に `NotificationChannel` を実装し、実在の宛先ではなくテスト用の宛先で動作を確認してから本番の宛先を設定する。
