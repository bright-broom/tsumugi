# 0013 未使用コードの整理と再混入の検査

- 状態：採用
- 日付：2026-09-14

## 背景

料金・ヘッダー・フッターの更新後、呼ばれない比較図、古い文言、未使用のアイコンとCSSが残っていた。既存の型・lint検査だけでは、未使用のexportやファイルを検出できなかった。

## 判断

静的生成の入口、npmスクリプト、単独実行の料金レポート、CSS・OGP生成を含む参照を確認し、呼び出し先のない実装を削除する。将来のためだけのexportも残さず、内部で使う値や型はファイル内に閉じる。

| 対象       | 整理したもの                                                                                                             |
| ---------- | ------------------------------------------------------------------------------------------------------------------------ |
| 関数       | 旧比較図の `afterTwoYears`・専用の狭幅版、未使用の `singleVsSubsMonths`                                                  |
| データ・型 | 未参照の料金版、アップグレード月数、他社最低契約月数、スポット料金表、`Locale` 型                                        |
| export     | 税率・着手金率・既定言語・Cards/Vsの内部型を非公開化                                                                     |
| カタログ   | 削除した図解や旧ヘッダー等の未参照37項目。現役の共有ラベルは維持                                                         |
| アイコン   | 呼び出しのない15種と、そのLucide import                                                                                  |
| CSS        | 旧料金切り替え、CTAパネル、未使用のラッパー・4列カード・任意入力ラベル等、24セレクター（17ルール全体と共有ルールの一部） |

使用中の図解・アイコン、フォームの設定に応じた分岐、キーボード操作や疑似要素のスタイル、デザイン仕様のトークンは維持する。動的にクラス名を組み立てるOGP画像のCSSと、文書から実行する料金レポートも現役のため保持する。

## 再混入を防ぐ仕組み

- `config/knip.config.ts` で、Pages Routerの入口、CSSの入口、単独実行の料金レポートを明示する。ESLint・Vitestの設定も実際の配置から読む。
- `npm run check:unused` で未使用のファイル・export・型・依存関係を検査する。`check` → `validate` → CI・Vercelにも組み込む。包括的な除外設定で問題を隠さない。
- TypeScriptで未使用変数・引数、到達不能コード、未使用ラベルをエラーにする。
- カタログのオブジェクト内プロパティとCSSセレクターはKnipの検査だけでは網羅しない。今回は型の参照先・動的アクセス・生成HTMLを照合して監査し、表示の比較も行う。以後も削除時には実際の利用経路を確認する。

Knipの入口とプロジェクトの設定は [公式の設定リファレンス](https://knip.dev/reference/configuration) に従う。既存の実行依存はすべて利用を確認できたため、削除はない。Knipだけを開発依存に追加する。

## 表示を維持するための検証

今回の変更は未使用CSSの削除を含むため、公開CSSのハッシュは変わる。コード整理に伴う意図した差分として、次の基準で確認する。

1. 変更前の `main` をビルドし、公開50ファイルのSHA-256を保存。
2. 変更後はCSSを除く49ファイルが完全一致。HTML21枚、公開文言・料金・図解・画像は同一。
3. `theme.css` は89,107バイトから87,106バイトへ2,001バイト減少。
4. 同じChromiumで全21ページを幅320・390・768・1440px、通常時とメニュー・FAQ展開等の状態で比較。全要素の配置と標準CSSプロパティ、疑似要素を確認する。未使用のカスタムプロパティ定義そのものは比較から除き、実際に適用されたスタイルを比較する。
5. 型・構造・未使用コード・lint・単体テスト・ビルド・納品検査を実行。

アイコンの単体テストは登録されている全アイコンを列挙するため、対象15種の削除に伴って122件から107件になる。公開ページの検査対象・しきい値は変更しない。

クリーンな `npm ci` と未使用検査に成功し、依存監査は0件。単体107件・料金モデル9件、全検査603 PASS / WARN 1 / FAIL 0（静的358 PASS）を確認した。WARNは既存の公開準備中設定によるもの。一時的な未使用ファイル・未使用変数を追加する確認でも、それぞれKnipとTypeScriptが失敗し、取り除くと合格することを確認した。

表示比較：全21ページ × 幅320・390・768・1440px × 通常／展開状態の168組で、全要素の配置・標準CSS・疑似要素が一致。描画完了を待って比較し、許容差の拡大や表示差分の除外は行っていません。
