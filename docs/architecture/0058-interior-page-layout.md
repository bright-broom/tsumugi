# 0058 — 全ページを目的に応じた読みやすいレイアウトへ揃える

日付：2026-09-17。状態：採用。

## 課題

TOP の改修後も、下層ページは見出し・説明・表が同じ幅で縦に続き、長いページでは目的の情報へ移動しづらかった。問い合わせページでは説明の後に連絡先があり、業種別ページでは共通の所有説明が具体的な用途・費用より前にあった。FAQ と契約条件も本文の位置を追いづらかった。

## 決定

- `Base` の本文にページ・種類の識別子と下層ページ用のクラスを付ける。`interior.css` を既存の中央管理 Tailwind の入口から読み、TOP と同じ幅・余白・線・文字の強弱を共有する。TOP・共通ヘッダー・フッターの既存デザインは維持する。
- 通常のサービスページは、見出しと導入文を PC で左右に配置。図解・比較表は広い領域を確保する。
- FAQ・仕様・契約・プライバシー・引き継ぎなどの長文は、`Section` の `reading` を明示して左に見出し、右に本文を置く。PC の見出しはスクロールに追従し、モバイル・印刷では通常配置に戻す。
- `PageIndex` を共通化し、ラベルと移動先を i18n の `shell.pageIndex` に集約する。主要な長文ページに目次を追加。FAQ は既存のカテゴリ別目次を整える。法定表示・404 の短いページへ不要な目次は足さない。
- 問い合わせはメール・電話を冒頭に置き、事前の説明を後ろへ移動する。メールアドレスは `@` の前で折り返せるようにし、リンク先とコピー可能な文字列は維持する。
- 業種別ページは「掲載する内容 → 制作費 → 毎月の費用 → 対応しない内容 → 共通の所有説明」へ並べ替える。必要な情報はチェックアイコン付きの 2 列、モバイルは 1 列。飲食店専用の比較・既存アンカーは保持する。
- 料金では買い切りの入口を主役に、自己管理を含む 4 つの継続支援の選択肢を PC では横に比較する。提供条件の注意は制作プランの近くで常時表示する。
- 補助金・掲載費の見直しは図解の後に明細を置く。制作事例は実測情報を掲載方針より前へ移す。404 はトップへ戻るボタンを主操作にする。

所有の共通カードは意味に合った地球・コード・ピン・写真のアイコンを指定し、アイコンと重複する丸数字を除く。TOP の開閉欄にも同じ正本を反映する。

金額・契約条件・専門家確認の状態・担当者情報は変更しない。図解数を維持し、折りたたみによる重要条件の非表示は増やさない。

## 採用と実装

共通 frontend-design ガイド 1.0（2026-09-14）を参照。導入済み React 19.3.0 / Next.js 16.3.5 Pages Router / TypeScript / Tailwind 4.3.3 を継続する。Lucide React 1.45.0（npm の公式 `lucide-react`、lockfile 固定）から `ArrowDown` と `ArrowUpRight` を明示的に追加し、目次・メールの移動方向に使う。新規依存・外部素材・外部通信は追加しない。ネイティブのアンカー・details と CSS で完結し、実行時 JavaScript 0 を維持する。

表示用属性・装飾 SVG・折り返し位置の追加に伴い、既存テストの HTML 完全一致を意味の検査に変更した。main のランドマーク、メールアドレス表示と mailto、フォーム非表示は引き続き検査する。検査のしきい値や公開条件は緩めない。
