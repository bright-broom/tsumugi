# 0060 — ヒーロー画像の上端を保持する

日付：2026-09-17。状態：採用。

TOP の高さを抑えた表示枠（ADR 0057）に対して、背景画像を上下中央で cover していたため、PC で人物の頭が切れていた。`object-position` を `78% 50%` から `78% 0%` に変更し、画像の上端を保持する。ADR 0029 の左右の位置、コピーを画像内に重ねる構成、ヒーローの高さは維持する。画面比率によって下端・左右が切れる仕様は継続する。

共通デザインガイドに従い、既存 Tailwind 4.3.3 の中央管理 CSS のみを変更。素材・依存追加はない。幅 320 / 390 / 768 / 1024 / 1440 / 1920 / 2560 px の Chromium で、画像の上端、ヘッダー直下の配置、コピーの収まり、横はみ出しなしを確認。

`validate` 合格（Vitest 518 件、料金モデル 12 件、21 ページの実行時 JS 0）。本番モード全項目は PASS 581 / WARN 3 / FAIL 0。既存の専門家・受入確認の WARN は残る。検証ログと画像は `.artifacts/hero-top/`。実機 Safari・本番サイトでの確認は未実施。
