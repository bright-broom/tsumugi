# 0062 — 全プランの比較ページを追加する

日付：2026-09-17。状態：採用（ページ構成）。掲載する検討価格の販売採用とは別。

## 目的

全プランをまとめた Excel をもとに、顧客が用途と提供範囲から比較できる `/plans.html` を新設する。既存の `/price.html` は支払い・増築・他社比較・ドメイン取得の詳細として残す。

## 決定

- 制作 3 プラン、個別 CMS・独自機能・有料設計、現行月額 4 プランと検討中の技術保守、追加オプション 8 項目、総額 6 例、契約前の確認を掲載する。
- CMS は「受付準備中」。個別 CMS・独自機能・設計・技術保守はそれぞれ価格の近くに「検討中・未発売」を表示し、申し込み操作を付けない。既存契約・販売用のプラン一覧や社内見積もりの商品一覧は変更しない。
- 参考価格は `src/content/prices.ts` の `PROPOSED_PRICES` で管理する。全項目に `status: 'concept'` を付け、`productionPlans()` / `RUN` / `OPTIONS` に追加しない。外部費の試算前提も同ファイルに集約する。
- 新ページの原稿は `i18n/locales/ja/catalog.ts`。ルート・OGP・メニュー・フッターを同じ台帳へ接続し、料金ページからも比較ページへ案内する。静的な見出し・ラベルも JSX へ直接記述しない。
- 営業原価、受注構成、利益、獲得費等の社内試算は掲載しない。顧客の比較に必要な提供範囲と費用を掲載する。社内情報を含む Excel のダウンロードリンクは公開ページに置かない。

## デザインと採用記録

共通 frontend-design ガイド 1.0 の既存部品・ブランド優先の方針を適用。既存の Lucide React 1.45.0（公式配布元 https://lucide.dev/guide/react 、ローカル LICENSE は ISC）を再利用する。新規依存・外部フォント・画像生成・クライアント JavaScript は追加しない。

アイボリー・エスプレッソ・琥珀のテーマを継続。導入は明朝、価格と本文はゴシック。制作カードを 3 列、月額を 4 列、追加作業を 2 列で比較し、狭い画面では縦に配置する。価格・用途・状態を先に見せ、詳しい納品条件は既存の `Acc` / HTML `details` で開閉する。

静的スタイルは `src/styles/catalog.css` の Tailwind `@apply` に集約し、既存 `globals.css` から読み込む。総額表だけを独立した横スクロール領域にして、フォーカス可能なラベル付き領域としてキーボードでも操作できるようにする。

## 検証

テストは既存の全ページ描画・和欧文間隔・ルート一覧に新ページを含める。追加の 4 テストで、検討価格の販売一覧からの分離、有料設計の二重計上防止、6 例の総額、未発売表示と申込み操作の不在を検査する。

幅 320 / 390 / 768 / 820 / 1024 / 1440 px の Chromium（実行時 JavaScript 無効、動きを減らす設定）で、横はみ出し、14 px 以上の本文・補助文字、6 箇所の目次、Enter による詳細開閉、表の矢印キースクロール、料金ページからのリンクを確認。画面画像と記録は `.artifacts/plans/`。実機 Safari は未確認。

最終のビルド・本番モード検査結果は [現状](../status.md) と [仕様](../spec.md) に記載する。本番 URL への配備はこの作業では行わない。
