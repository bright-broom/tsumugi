# 0066 商品の提供準備状態を見積発行に適用する

- 日付：2026-09-18
- 状態：採用（ブランチ実装、main 反映は status.md 参照）

## 背景

監査 C03。制作プランの preparing は保存時に検査していたが、追加オプションには価格の確定度 firm しかなかった。多言語は価格表に存在する一方、getMessages は ja 以外を拒否し、言語別ルート・出力・表示品質を提供できる検証証跡がない。価格確定を提供可能と扱うと、未準備の商品を見積書として発行できる。

## 判断

OPTIONS の全商品にも preparing を明示する。現状の提供条件を維持し、多言語だけを準備中として保守的に停止する。これは翻訳・言語別表示の実装や販売開始の決定ではない。料金は全て維持する。参考価格かどうかを表す firm と提供状態を分離し、価格が目安でも提供可能な撮影等の既存経路は維持する。

公開料金表と全プラン比較、見積試算・保存・再出力が同じ価格表を参照する。提供状態が未指定の場合も保存・発行を止める。試算は金額と blockers を返すが、見積書ではない。

保存済みの版の再出力も現在の提供状態で検査する。準備中商品の旧版は JSON と差分として保持し、正式な見積書の再出力は止める。過去の金額を再計算して書き換えない。価格表の指紋に準備状態を含め、同じ入力でも価格表が変わった場合は別版として保存できる。入力も価格表も同じ場合は重複保存しない。

## UI と採用記録

共通フロントエンドガイド（2026-09-14、版 1.0）の既存部品再利用方針を適用。既存 Table、catalog-option、Tailwind 4.3.3、Lucide 1.45.0 を継続し、ライブラリ・アイコン・CSS の追加はない。価格の近くに受付準備中を文字で表示し、購入操作を付けない。Noto 等への書体変更は行わず、プロジェクト既存のブランド構成を維持する。共通ガイドはローカル README / GUIDELINES、使用部品の取得元・固定版は package.json / lockfile。

## 検証と未完了

金額確定と準備状態の独立性、未指定状態、保存拒否、過去版の再出力拒否、失敗時にファイルを変更しないこと、旧価格の保持、価格表変更後の再保存を検査する。料金表とプラン比較の狭い／広い画面、JS 0、型・lint・全テスト・ビルド・本番条件を確認する。結果は [status.md](../status.md)。実機 Safari、多言語自体の実装・翻訳・外部サービスの提供体制は未検証。既に外部へ渡した見積を撤回する機能は含まない。
