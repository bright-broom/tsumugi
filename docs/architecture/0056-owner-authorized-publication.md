# 0056 — 自社サイトの公開判断を専門家確認・顧客の納品検収から分ける

日付：2026-09-17。状態：採用。ADR 0024・0026 の自社サイト公開条件を更新。

## 公開の根拠

オーナー（作田 敏希）は、本番が準備中設定・利用規約と法定表示の専門家確認記録・受入確認記録の不足で停止しているという説明の後に、「公開できるようにして」と指示した。これは紬の自社サイトの公開指示として記録する。専門家レビューや実機・実通話・メール送受信の完了を表す指示ではない。

対象は https://tsumugi-six.vercel.app/ 。問い合わせは既存の電話・メール案内で、オンライン決済・契約締結・問い合わせフォームは設けない。独自ドメインの取得は今回の公開条件にしない。

## 決定

- 実際の事業者情報が入力済みのため `PLACEHOLDER=false` にする。
- `src/content/publication.ts` にオーナーの公開判断を独立して記録する。対象ドメイン・事業者・指示日・この根拠文書・契約文面 2 件の SHA-256・未確認項目の一覧を明示する。
- 対象が一致する場合だけ、空の専門家確認記録 2 件と記録に列挙した未確認項目を本番検査の WARN にする。PASS や確認済みへ書き換えない。`LEGAL_APPROVALS` と `ACCEPTANCE_RECORDS` は空のまま保持する。
- 承認日が不正・未来、対象ドメインや事業者が異なる、文面のハッシュが変わった、未確認項目が増えた場合は公開判断を更新するまで FAIL。専門家記録の一部だけの記入・破損した専門家記録も FAIL のまま。
- 仮の事業者情報、未接続フォーム、静的検査・ブラウザ検査・セキュリティ検査の不備は引き続き停止条件。本番をプレビューモードで配備する仕組みは追加しない。
- 利用規約ページは下書きの表示を保持。「公開前に確認する」という旧文言だけ、事実に沿った「専門家による確認は未実施です」へ変更する。個別契約は確認後の書面で取り交わす案内を保持する。
- 顧客テンプレートへの転用時は `OWNER_PUBLICATION=null` に戻す。顧客への納品検収の代替にしない。
- CI の全項目検査も本番モードへ変更し、プレビューの成功だけで main に入らないようにする。

## 検証・配備・切り戻し

公開条件の回帰テスト、型・lint・全単体テスト・価格テスト・静的出力の安全性、全ページのブラウザ検査を行う。CI と Vercel プレビュー成功、および商用プランの確認後に PR で main へ統合する。本番 URL で全ページの HTTP・canonical・連絡先・セキュリティヘッダーと CSP の正常表示を確認する。結果は docs/status.md に記録する。

既存の静的サイトのみを更新し、データ移行はない。公開後に連絡先・主要ページ・CSP・表示の不具合が出た場合は、Vercel の直前の Ready 配備へ戻すかこの変更を revert し、原因を修正して検証し直す。通知・顧客情報の実送信は今回実施しない。

## 残る確認

専門家の契約文面確認、実通話・メール受信、実機操作、外部サービスの運用確認は未実施。自動検査レポートの acceptance に未確認項目を残し、営業上の確認済み実績には使わない。公開の許可とこれらの確認の完了を区別する。

公開先の契約：2026-09-17 の API 確認では Hobby。商用公開に必要な契約変更はオーナーの費用承認後に行う。コードの公開許可を、新たな有料契約の承認とは扱わない。
