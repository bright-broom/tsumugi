# ADR 0006: 紬の和モダンな共通ヘッダー

- 日付: 2026-09-14
- 状態: 採用

## 背景

国生みのヒーロー画像に対して、従来の小さなロゴ、説明、アイコン付きナビ、電話の並びは密集していた。利用者から「モダンで、少し和風」の美しいヘッダーへの変更が指定された。

## 決定

- `components/Header.tsx` に全21ページのヘッダーをまとめ、`Base` はページの器に専念する。
- 生成り・藍墨・真鍮色の細い罫線と余白で構成する。屋号に限り端末の明朝を採用する。初期の明朝不使用方針と62/54pxの高さを更新し、88/72pxをトークンと静的検査の契約にする。
- 既存の4本の主ナビの行き先を保ち、装飾アイコンを除く。問い合わせを常時表示し、全体メニューをPCにも追加する。
- メニューは `details` / `summary` で開閉し、全主要ページと業種別ページ、電話へ移動できる。開閉状態の読み上げはブラウザに任せ、表示ラベルをCSSで切り替える。
- 文言は `i18n/locales/ja/shell.ts`、URLはルート登録を利用する。電話表示は共通 `PhoneLink` を利用する。
- 新規のUIライブラリ・外部フォント・実行時JavaScriptを追加しない。Lucideは静的SVGとして出力する。

## 影響と検証

画像はヘッダー直下のまま。本文、料金、OGP画像は変更しない。既存のスクロール余白も高さトークンに追従する。既存検査に問い合わせ、欧文屋号、メニュー操作、PC電話のコントラスト対象を追加する。型・文言・lint・単体テスト・静的出力・全ページのブラウザ検査に加え、幅320〜1440pxと開いたメニューのキーボード操作を確認する。

端末ごとに明朝の字形は変わる。外部フォントを取得せず、屋号の字形の完全固定は要求しない。標準のメニューはモーダルではなく、Escapeキーや外側クリックによる閉じ方を追加しない。summaryの再操作で閉じ、ページ遷移すると閉じた状態に戻る。
