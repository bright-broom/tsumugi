# 0019 画像内コピーもi18nから描画する

- 日付：2026-09-14
- 状態：採用。ADR 0005の文字の描き込み・併記方針を置き換える

## 問題

本文・ボタン・フォーム・図解・ページ情報・OGPの文言は日本語カタログにあるが、ヒーローの文字は元絵にも描かれていた。PC用のHTMLコピーは読み上げ用に隠れており、カタログの変更だけでは目に見えるコピーを更新できなかった。電話番号・メール・郵便番号も `content/config.ts` に残っていた。

## 判断

- 背景画から文字を除き、見出しと本文は `i18n/locales/ja/home.ts` の `hero` を渡したHTMLで表示する。PCは画像左側に重ね、768px以下は画像の下に置く。
- 背景画は同じ寸法のWebPを自己完結SVGに内包する。SVGのタイトルは絵の説明だけにし、見出し・本文を重複させない。SVGはラスター画像のラッパーであり、ベクター化ではない。
- 文字除去には元画像を参照した画像編集を使った。描写・配置を保つ意図だが、背景の細部は一部再生成されている。原本の来歴は `src/assets/hero/README.md` に記録する。
- 連絡先の表示値を `i18n/locales/ja/config.ts` に移す。`content/config.ts` の既存exportはカタログを参照し、発信先は同じ番号から作る。
- 金額・計算・実測値・URL・送信先・技術識別子は、それぞれのデータと設定の責務に残す。1ビルド1言語の方針は維持し、言語切り替え機能は追加しない。
- ソース検査を拡張し、英語を含むJSX式、条件分岐、テンプレート、案内属性、ラベル等のオブジェクト値の直接記述を検出する。技術識別子や関数引数を一律に翻訳対象とすることは避ける。この検査は任意のデータフローや画像内文字を解析するものではないため、新しい素材は目視も必要。

- ヒーローの4つのコピーと代替説明を変更したページ入力がHTMLに反映されるテストを追加。ソース検査の抜け道と技術文字列の許容も検査する。
