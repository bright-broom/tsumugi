# 0005 — 国生みの画像を SVG で暫定配置する

- 日付：2026-09-14
- 状態：画像配置は暫定採用。文字の描き込みと併記の判断は [0019](0019-complete-i18n.md) に置き換え

## 判断

利用者が指定した「イザナギ・イザナミとおのころ島」の生成画像を、ホームのヘッダー直下に配置する。従来の「ヒーローに画像を使わない」という判断を、このページについて変更する。既存の所有・料金・問い合わせの案内は画像の下に残す。

日本画の細部を保ちつつ容量を抑えるため、同寸法の WebP（品質90、568,396 バイト）を SVG に埋め込む。SVG は約741 KiBで、外部画像・フォント・スクリプトに依存しない。これはラスター画像を内包した SVG であり、拡大しても細部が増えるベクター化ではない。元絵は `site/assets/hero/onokoro.webp`、生成は `build-public.ts` が担う。

## 表示と文言

- 通常の `img` で読み、縦横比を維持して全幅表示する。固定高や `object-fit: cover` による切り抜きはしない。
- `width`・`height` で表示領域を確保し、`fetchPriority="high"`・`loading="eager"` で先頭画像を優先する。JS ランタイムを追加しない。
- ページの h1 は新しいブランドコピーにし、従来のサービス見出しは h2 にする。
- 768px以下では画像の下に読みやすい HTML のコピーを併記する。広い画面でも同じ見出しと本文を読み上げで利用できる。
- 見出し・本文・画像の代替説明・SVG のタイトルと説明は日本語カタログで管理する。

画像内の文字は暫定素材に描き込まれたままなので、カタログだけでは画像内の文字を変更できない。本採用時は絵と文字を分離する。それまではカタログと画像を一緒に変更する。

## 検証

HTML 属性名は大小文字を区別しないため、先頭画像の検査を React が出力する `fetchPriority` にも対応させる。低優先度や lazy を合格にする変更はしない。従来のヒーロー見出しのコントラスト対象を保ち、新しい HTML コピーも検査する。

PC・390px・320pxで画像の表示、ヘッダーとの連続、横はみ出し、h1が1つであること、ブラウザが認識する画像優先度を確認する。全21ページの静的検査・ブラウザ検査、型・lint・単体テストと実行時JS 0バイトを維持する。ローカルの LCP はネットワーク制限なしの計測であり、実利用者の通信速度での値を保証するものではない。
