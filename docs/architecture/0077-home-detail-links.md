# 0077 トップの各セクションから詳細ページへつなぐ

- 日付：2026-09-19
- 状態：採用（main 反映は status.md 参照）

## 背景

トップページ本文から直接行けない詳細ページがあった：全プラン比較（plans）・掲載費の見直し（cost-cut）・制作の流れ（flow）・制作事例（works）・よくあるご質問（faq）。ヘッダーのメニューとフッターからは全ページへ行けるが、読み進めている途中の内容から詳しいページへ移れなかった。月額制との比較・FAQ・相談の3セクションには、詳細ページへのリンクが1つもなかった。`Section` の `navKey` はアイコンを出すだけで、リンクではない。

## 判断

共通部品 `RouteLinks`（`src/components/RouteLinks.tsx`）を追加する。ルートIDの一覧を受け取り、`content/nav.ts` の `routeLinks` でヘッダー・フッターと同じ文言（`nav.labels`）・アイコン・パスを使う。新しい文言は作らないため、ナビとの表記ゆれが起きない。

| セクション     | 追加した導線                                                         |
| -------------- | -------------------------------------------------------------------- |
| 料金           | 料金・全プランを比較                                                 |
| 借地と所有     | ソースコードの納品・納品する仕様（既存の「条件を見る」ボタンは維持） |
| 月額制との比較 | 掲載費の見直し・料金                                                 |
| よくあるご質問 | よくあるご質問                                                       |
| 相談           | 制作の流れ・制作事例・私たちについて・相談する                       |

既存のボタン・本文内リンクは変更しない。業種・変更と継続支援・補助金は既存の導線で足りている。

表示は罫線区切りのリンク列。1件は1列、4件は1025px以上で4列、それ以外は2列、768px以下は1列にして、端数の折り返しを作らない。濃色と琥珀色のセクションは文字・罫線の色だけを切り替える。実行時 JS は増えない。

## 検証

`tests/home-routes.test.tsx` がトップページを描画し、`<main>` の本文だけで全ての詳細ページ（main・業種の全ルート）へ移動できること、ヒーロー以外の9セクションすべてに詳細ページへのリンクがあること、導線の文言がナビのラベルと一致することを確かめる。変更前のトップでは3件とも失敗することを確認した。公開出力の差分は `index.html` と `theme.css` のみ。
