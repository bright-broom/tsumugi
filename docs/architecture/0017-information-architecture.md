# ADR 0017: 情報を意味のある単位で共有する

- 状態: 採用
- 日付: 2026-09-14

## 背景と判断

全21ページを確認すると、所有の4項目、ホームとFAQの回答、ヘッダーとフッターのページ案内に、同じ情報の別管理があった。FAQの回答は111個の文言断片を表示側で組み立てており、同じ質問でもホームと詳細で説明がずれる余地があった。

文言の短い断片ではなく、所有の項目・質問と回答・案内のグループを共有する。FAQの30問は安定IDを持ち、6カテゴリとホームの抜粋5問が同じ正本を参照する。金額等は事業データから差し込む。FAQにカテゴリ目次を追加し、各質問にも固定のアンカーを付ける。所有の4項目は既存のCardsで描画する。

ヘッダーの全体メニューとフッターの13主要リンクを、共通の3グループに分類する。ルートの定義・URLは台帳が正本で、見出しとリンク名はi18nに置く。業種4件と法務3件の導線、ヘッダーの主な4リンクは維持する。

ページごとの役割と共通化の境界は [情報設計](../product/information-architecture.md) に記録した。価格・契約の注意、業種特有の説明、図解・比較の不利な行は残す。全ページを一つのテンプレートに押し込むことはしない。

## 文言の整合

原稿作成の回答を採用済み料金の範囲に揃え、入口プランは支給素材からの整理、追加取材は別見積もりとした。実績は自社サイト1件と今後の顧客事例を区別する。ホームの広告回答をFAQに加え、ホームのその他4問は同じ題材のFAQの回答を使用する。

## 出力差分

今回は情報の案内と表示内容を変えるため、HTMLの完全一致を合格条件にしない。全ページのメニューとフッター、FAQの目次・見出し・回答、ホームのFAQと所有の説明、所有ページの4項目が意図した差分である。CSSはグループ見出しとFAQ目次の追加。既存の3色・図解・ヒーロー・OGPは変更しない。

## 検証

型・構造・文言・未使用コード・lint、単体113件（情報設計の回帰検査6件を追加）、料金モデル9件を確認。標準検査は603 PASS / WARN 1 / FAIL 0、静的検査は358 PASS / WARN 1 / FAIL 0。警告は既知の仮設定のみ。実行時JSは全21ページで0。

Chromiumで全21ページを1440・390・320pxの63組で確認し、文字・図のコントラスト、横はみ出し、同一ページ内のリンク先、ID重複、展開したメニューの幅に失敗なし。本文のアコーディオンも展開して検査し、FAQのカテゴリ移動と回答の開閉を確認した。PC・スマートフォンの変更前後のFAQ、メニュー、ホームFAQ、フッターを保存し、代表画面を目視した。

ホーム・所有・FAQを除く18ページのmain内部は変更前と完全一致。HTMLとCSS以外の28ファイルもハッシュ一致し、画像・フォント・サイトマップ等の意図しない変更がない。ヘッダーの新たなアイコン重複を避け、ホームHTMLは100KB未満の既存基準を維持した。フッターのアイコン32個とホームの図解4点は保持する。

本番デプロイと実機Safariの検証は今回の範囲外。
