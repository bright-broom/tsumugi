# 0074 — 案件を進める直前に見積参照を再検証する

日付：2026-09-18。状態：採用。関連：#27、D04。

## 問題

ADR0073は新しい紐付けを照合するが、以前からあるCRM参照や、紐付け後に削除・差し替えられた見積は、状態を進める際に確認していなかった。状況表示もファイルの存在を確認せず「進められます」と案内していた。

## 決定

見積提出・契約済み・制作中へ進める直前に、案件が参照する全見積を共通ロック内で再読込する。少なくとも1件が必要で、保存ファイル・内外の番号・指定版・顧客・案件を照合する。通常の状態遷移条件と両方が通ってから顧客ファイルを保存する。

showでも同じ条件を用い、進められない理由を表示する。確認のために履歴やデータを書き換えない。相談への差し戻し・中止を妨げない。純粋な状態遷移モデルはファイルIOを持たず、CLIが保存直前の照合を担当する。

## 旧データと範囲

帰属のない旧見積を参照する案件も、上記3段階への進行時に停止する。バックアップから正しい見積を復元するか、担当者が参照と帰属を確認して修復する。AIがIDを推定したり、旧参照を黙って消したりしない。

期限切れの見積を締結済みの契約から機械的に排除する処理ではない。金額・署名・契約との対応・実送付や認証権限を証明しない。後半の検収/引渡し段階の条件は既存のまま。D04全体は継続する。

## 検証

3つの遷移それぞれで、欠落・版違い・顧客違い・案件違い・旧版・番号違い・参照なし・正常系を実CLIの別プロセスで確認（24件）。失敗時は顧客ファイルのバイト列が不変、showも読取りだけで理由を表示する。相談への差し戻し1件を加え25件。全体結果はstatus.mdを参照。
