# ADR 0063: デザイン変更の責務と回帰検証

日付: 2026-09-17

## 背景

今後、配色・部品・ページ構成を複数回、大幅に変える予定。料金・文章・URL は既に分離されているが、共通部品の CSS は 1,247 行に集中し、共通の文字サイズとボタンのクラス指定が各ページで重複していた。

## 判断

1. `components.css` を import の入口とし、共通部品を 20 個の役割別 CSS に分割する。既存の `@layer`、セレクター、import 順序を維持する。全面的な CSS Modules 化や別 UI 基盤への移行はしない。
2. 共通の 14 / 15 / 16 / 18 / 20 px の文字と 4 / 8 px の角丸を既存・追加トークンへ統合する。下層の章間・ページ先頭の余白も JSON から変更できるようにする。トークン数は 99。
3. リンクは `ActionLink`、ボタンは `ActionButton`、電話は `PhoneLink` の `variant` を利用する。DOM のタグ・属性・順序・リンク先・ARIA は維持し、`ActionButton` の既定は送信しない `type="button"`。
4. 型検査の既存スタイル境界を拡張し、共通寸法の直接指定とページ内の直接の `btn` 指定を検出する。すべての静的解析が動的な任意の文字列合成を完全に捕捉するという保証ではない。
5. 変更前後の静的出力を同じ Chromium で比較する `design:compare` を追加する。全 HTML を列挙し、4 幅の全ページ画像と全ファイルの SHA-256 を残す。差分を失敗として報告し、基準画像は自動更新しない。

料金、販売・準備中・検討中の状態、i18n、ルート、サイトの公開情報、実行時 JS 0 は維持する。ブラウザ上のテーマ設定機能は作らない。デザインの切り替えは JSON / CSS / React を編集し、ビルドする方式。

## 責務と残る制約

- 編集場所と手順は [リデザイン手順](../product/redesign-guide.md) を正本とする。
- 既存の `screens`・`overrides` のカスケードは保存した。下層共通の例外は `interior.css`、ページ固有は該当ページ CSS に残る。新規変更で同じセレクターの後付け上書きを増やさず、所有するルールを編集する。
- 図解の座標、ページ固有の価格表示、ヒーローの比率まで同じトークンにしない。
- 既存の React 19.3.0 / Tailwind 4.3.3 / Lucide 1.45.0 / Playwright 1.63.0 を使用。外部素材・依存パッケージ・実行時 JS は追加しない。共通デザインガイド 1.0 の既存基盤優先・部品再利用方針を適用。

## 検証

- 全 22 ページ × 320 / 390 / 768 / 1440 px = **88 パターンすべてで全ページ PNG が完全一致**。ページ全体の横はみ出し 0。
- 52 出力ファイルのうち、変わったのは `theme.css` のみ。**HTML・画像・フォント等の 51 ファイルは SHA-256 が一致**。生成 CSS 内のトークン参照と部品の出力構成の変更は意図した差分。生成方式を変更するリファクタリングの例外として、全ページの同一ブラウザ比較で表示の同一性を確認した。
- 比較時は変更前後とも検証レポートの有効状態を揃えた。最終コミット後の `works.html` は同コミットの検証記録を反映するために再ビルドする。
- `npm run check`・lint 合格、Vitest **530 件**合格。新規テストは通常リンク、意図しないフォーム送信の抑制、明示した submit / disabled / ARIA、電話番号の一貫性、重複指定の検出を確認する。
- ビルドは全 22 ページで実行時 script 0。本番モード検査 **PASS 600 / WARN 3 / FAIL 0、対象なし 42**。既存の専門家・受入確認の WARN を維持し、検査のしきい値は変更しない。
- 比較コマンド自身は、同じサイトで成功、CSS だけ変えたサイトで 4 幅すべての差分を検出することを確認。自動で基準画像を採用しない。
- `.artifacts/design/final-comparison/index.html` と `report.json` に画像・ハッシュ・測定幅を保存（Git 管理外）。
- 実機 Safari と Vercel 本番への反映は、この変更の検証対象外。
