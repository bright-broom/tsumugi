# 0087 装飾付きの本文は HTML 文字列のまま残し、許可リストで検査する

- 日付：2026-09-26
- 状態：採用

## 背景

#56 の残りは「画面の構造を型付きの React へ移し、生 HTML の差し込み経路を用途ごとに整理する。装飾付き翻訳は危険な挿入を増やさずに表す」だった。[ADR 0022](0022-pricing-typescript.md) は、`Flow`・`Table`・`Section`・`Calc`・`Note`・`Acc`・`Cards` と一部の views が `raw()`（`dangerouslySetInnerHTML`）で装飾本文を描くことを棚卸しし、型付きの描画へ置き換える方針を書いていた。

2026-09-26 の時点で、`raw()` の呼び出しは 26 か所。ビルドで実際に `raw()` へ渡った HTML を集めると、使っているのは次だけだった。

- 文字の装飾：`strong`（126）・`p`（37）・`span class`（29）・`br`（28）・`em`（4）
- 自サイトへのリンク：`a href="/….html"`（20）
- アイコンの SVG（`lib/ic` が Lucide から作る）：`svg`・`path`・`circle`・`rect`・`line`

## 判断

**全面的な型付き描画への置き換えはしない。代わりに、`raw()` に渡る HTML を許可リストで検査し、外れたらビルドを止める。**

- 置き換えの費用に対して得るものが小さい。日本語カタログ全体（`strong` だけで 126 か所）の書き換えになり、翻訳の単位（1 文の中の強調）を部品側へ分解すると、差し込み値や語順が言語ごとに違う多言語（[ADR 0081](0081-build-time-locales.md)）でかえって扱いにくくなる。
- `raw()` の危険は「信頼できない文字列が入ること」だけ。本文は自前のカタログで、CMS の記事は HTML を受け取らず型付きのブロックへ変換している（[ADR 0080](0080-microcms-content-source.md)）。この前提を**約束ではなく検査で**守れば、目的（危険な挿入を増やさない）は満たせる。
- 公開ページに JavaScript を載せないので、検査が動くのはビルドのときだけ。配信物にも実行時の負担にも影響しない。

### 許可するもの（`src/lib/raw.ts` の `ALLOWED`）

| タグ                                                         | 属性                                                                                         |
| ------------------------------------------------------------ | -------------------------------------------------------------------------------------------- |
| `strong` `p` `span`                                          | `class`                                                                                      |
| `em` `br`                                                    | なし                                                                                         |
| `a`                                                          | `href`（`/`・`#`・`tel:`・`mailto:`・`https://` で始まるものだけ）、`class`                  |
| `svg`                                                        | アイコンの表示に要る属性（`viewBox`・`stroke` 系・`class`・`aria-hidden`・`focusable` ほか） |
| `path` `circle` `ellipse` `rect` `line` `polyline` `polygon` | 図形の座標だけ                                                                               |

止めるもの：上にないタグ（`script`・`img`・`iframe`・`style`・`use` など）、上にない属性（`on*`・`style`・`src` など）、`javascript:` や `//` で始まるリンク先、タグとして閉じていない `<script` のような断片。

## 限界

- 許可したタグの組み合わせ（入れ子の正しさ、`p` の中の `p` など）までは見ない。見た目の崩れは表示の検査（`verify`・`design:compare`）が受け持つ。
- 検査はビルドで描画された文字列だけが対象。描画されない翻訳（公開していない言語）は、その言語をビルドしたときに検査される。

## 検証

- `tests/raw-html.test.ts`：本文で使う装飾・リンク・アイコンを通すこと、`script`・`onerror`・`onclick`・`javascript:`（大文字や前後の空白を含む）・`//` 始まり・`iframe`・`style` 属性・`use`・閉じていない `<script` を止めること、不等号の `<` を本文として扱うこと。
- 検査を入れた状態で `npm run build` が成功（22 ページすべての本文が許可リストの内側）。
