# 0053 飲食店の掲載料・予約手数料は飲食店ページにまとめる

- 採用日：2026-09-17
- ユーザー指定：飲食店専門の比較を、全業種向けの TOP ではなく飲食店ページに掲載する。

TOP の「毎月の費用」セクションを `restaurant.html#monthly-costs` へ移す。料金 4 行、Lucide の集客経路図、昼夜の予約手数料、任意支援・外部費・税込の注記、掲載費の詳細へのリンクを保持する。飲食店ページにあった短い費用説明をこのセクションで置き換え、二重に表示しない。他の業種にはこの比較を出さない。TOP の既存の業種別案内から飲食店ページへ移動できる。

文言は `home` カタログから `industry.restaurantCosts` に移し、業種テンプレートの入力として受け取る。比較金額は `content/prices.ts` の名前付き定数を使用する。比較のスタイルもホーム専用ファイルから `pages.css` の `.restaurant-cost` へ移す。共通デザインガイドに従い、既存の Section・Vs・Note・RentVsOwn を再利用。追加ライブラリは不要で、Lucide の採用元・版は ADR 0052 のまま。料金の改定や再調査は行っていない。

型・lint・Vitest 483 件・料金モデル 12 件・ビルドに合格。全項目 PASS 575 / WARN 1 / FAIL 0、静的 PASS 318 / WARN 1 / FAIL 0（対象なし 40）。飲食店以外の業種と TOP に対象セクションが出ないこと、金額・注記が保持されることを回帰検査。Chromium・JS 無効で TOP と飲食店ページを幅 1440 / 390 / 320 px で確認し、横はみ出しとリンク切れなし。検証画像は `.artifacts/restaurant-move/`（Git 管理外）。実機 Safari と本番配備は未確認。

TOP は 95.3 KiB、飲食店ページは 45.8 KiB になり、ADR 0052 で記録した TOP の容量警告は解消した。容量基準 100 KiB は変更していない。残る WARN は既存の本番公開条件の未設定のみ。
