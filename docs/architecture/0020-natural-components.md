# 0020 内容に合う部品と自然な読み順

- 日付：2026-09-14
- 状態：採用
- 対象：全21ページ。ADR 0007・0008の装飾と余白を見直す

## 問題

全ページのPC・モバイル画面を確認した。巨大な欧文ロゴの反復、角丸の箱が続く説明、用途の異なる情報の同じカード化、章ごとに繰り返す横罫線と大きな空白が、内容より目立っていた。相談案内の1・2・3・＝は実績数値のように見える。担当者紹介はgridの列指定だけがありdisplayがなく、業種案内はリンク3件に対して4列を固定していた。

## 判断

「AIらしさ」を一律に判定することはせず、読みやすさと内容の意味に対して不要な装飾を減らす。共通デザインガイド1.0とdesign-critiqueの視点で現物を評価し、既存の静的React部品・Lucide・Tailwindを再利用する。新たな依存関係は追加しない。

| 対象 | 更新 |
|---|---|
| ページ冒頭 | `Section`にpage-introの役割を与え、端末の明朝を見出しに使う。本文はゴシックのまま |
| 共通の余白 | PCの章は104→72px、冒頭と次の章はさらに近づける。すべての見出しへの横罫線を廃止 |
| ボタン・状態 | 丸薬型から控えめな角丸へ。未設定フォームの送信ボタンを視覚的にも無効にする。タップ領域とフォーカスは維持 |
| 説明・比較 | カードとパネルの角丸は4px。ホームの所有項目は2列、約束は要点・説明・リンクの行。料金の比較・推奨表示・受付準備中の条件は維持 |
| FAQ・手順 | 質問は罫線で区切る行、分類はリンク。担当と日程のピル型装飾を外す。ネイティブの開閉は維持 |

| 動き | 説明カードの縮小、スクロール進捗線、ページ切り替え演出を撤去。操作を示すメニューの開閉・ホバー・フォーカスは維持 |
