# ADR 0015: アクセントを琥珀色へ変更

- 状態: 採用
- 日付: 2026-09-14
- 更新対象: ADR 0014のアクセント色と文字の組み合わせ

## 判断

利用者の「Amazonのような黄色っぽいアクセント」という希望を受け、アクセントを朱から黄みのある琥珀 `#FFB000` へ変更する。生成り `#F7F5F0` と墨 `#243B3B`、イラストを除くUI面積の70/20/10という目安は維持する。

Amazonが公開している[ロゴ利用資料](https://images-eu.ssl-images-amazon.com/images/G/46/gc/Corporate/Logo_Usage_Guidelines_en_1.pdf)にはAmazon Orange `#FF9900` が示されている。今回はその印象を参考に、依頼の黄色寄りに調整した独自色を選ぶ。この資料は色が売上を増やす因果関係の根拠ではない。紬での成果は未検証であり、色の心理効果による売上増加を保証しない。

## 実装

- 原色は引き続き3値だけ。変更は `design.tokens.json` を正本として反映する。
- 琥珀のボタン・料金面には墨文字を使う。ヘッダー、フッター、相談、計算結果、共有カード、ファビコンの反転色を同期する。
- 明るい面に載る小さい強調文字と図の良状態は、琥珀25%＋墨75%の混色から導出する。独立した4色目を追加せず、意味のラベル・チェック・バツ・線を保つ。
- 暗い章のアイコンには琥珀を使う。相談の琥珀面では墨のアイコン・文字・フォーカス枠にする。
- OGP21枚、PNGアイコン2枚、SVGファビコン1枚を既存のmacOSフォント環境で同期する。共有カードの料金は墨文字＋琥珀の面で強調する。
- コピー、価格、ルート、アイコン数、ヒーロー原画、実行時JSゼロの仕様は変更しない。

型・lint・単体107件・料金モデル9件・ビルド成功。標準603 PASS / WARN 1 / FAIL 0、静的358 PASS。WARNは既知の仮設定。ホームの料金パネルと相談セクションをPC・スマートフォンで、OGPを実画像で確認した。全21ページ×390/1440pxの文字・図のコントラストと横はみ出しも42組で巡回し、失敗なしを確認した。
