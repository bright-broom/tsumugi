# ADR 0014: 生成り・墨・朱の3色システム

- 状態: 採用
- 日付: 2026-09-14

## 背景と判断

利用者の「3色にまとめ、メイン7割・サブ2割・アクセント1割」という指定に合わせ、以前の無彩色・緑・青・ヘッダーの真鍮色を、生成り `#F7F5F0`・墨 `#243B3B`・朱 `#B44B35` に統一する。既存の寸法・図解・アイコン・文章・料金・ルートは保持する。

メインは背景と余白、サブは本文と説明の章、アクセントは主要操作・料金・相談の面に使う。ホームの標準仕様の章を墨へ変更し、冒頭の料金パネルと最後の相談を朱にする。面積比率はヒーローイラストを除くUIの目安とし、長さが異なる全ページ・全画面幅に厳密な同一比率を強制しない。

## 正本と表示

`src/styles/design.tokens.json` の `color.main` / `color.sub` / `color.accent` の3色を正本にする。他の色は参照または3色の混色・透過。トークンは85→88個で、従来のトークン名は互換参照として残す。両PROFILEとも同じ3色を参照する。グローバルTailwindの構成を維持し、ページ単位のインライン色指定を追加しない。

`_document.tsx` のブラウザテーマ色とOGP生成のSVGもこのJSONを直接読む。依存検査にはこのデータ専用の末端JSONだけを許可する例外を追加し、CSSの任意importや上位層への依存は許可しない。

生成り／墨のコントラストは約10.93:1。朱の上の小さい文字を生成りに統一し、薄めない。暗い章でも図解のキャンバスは生成りとし、図の記号・ラベルによる状態の区別を保つ。ヒーローの原画は変更しない。

共有カード21枚とファビコン3種を同じパレットで再生成する。今回の生成環境はmacOS・既存のNoto Sans CJK JP / Hiragino Sansスタック・Playwright Chromiumとする（ADR 0011の料金更新と同じ既存設定）。書体の追加や変更はない。別OSでの完全な字形再現にはフォント環境の固定が引き続き必要。

## 検証

- 型・依存方向・文言・CSS・未使用コード・lint、単体107件、料金モデル9件、ビルドに合格。
- 標準検査603 PASS / WARN 1 / FAIL 0。静的358 PASS。WARNは既知の仮設定。全21ページで公開実行時JS 0。
- 全21ページ×幅390/1440pxの42組を追加巡回し、検査対象の文字・図中文字のコントラストと横はみ出しに失敗なし。主なホームセクション、ヘッダー・フッター、OGPを目視確認。
- 変更前の静的出力と全21ページのテキスト・リンク先・SVG数が一致。価格データ・文言カタログ・原画に変更なし。
- ホームの全長画像からヒーロー領域を除き、4px間隔で3原色へのRGB距離が最小の色へ分類した概算は、1440pxで72.1/20.0/7.9%、390pxで68.6/22.2/9.2%。混色や文字の縁も分類する簡易計測であり、知覚上の面積を厳密に測る指標ではない。

新しいCSSの `color(srgb …)` / `color-mix()` を従来の検査が0–255のRGBとして誤読する問題も修正した。ブラウザのCanvasでsRGB＋アルファへ正規化し、本文と図の両検査で使う。同じ色のRGB表記・CSS Color 4表記・反転の4ケースがすべて10.93:1になることを確認。合格のしきい値や検査対象は緩めていない。

検証はローカルChromiumで行い、実機Safariの確認や本番デプロイを意味しない。CIとVercelプレビューはPRの結果を参照する。
