# ADR 0007: 図解と情報を保持したホーム本文の刷新

- 日付: 2026-09-14
- 状態: 採用

## 背景

利用者から、ヒーローより下をより魅力的にし、アイコンと図解を豊富に残すこと、日本画のヒーローの雰囲気を本文に持ち込みすぎないことが指定された。

## 決定

白・淡いグレー・チャコールを基調に、既存のゴシックと大きな数字で構成する。冒頭は見出しと価格パネルの2列、比較図は広い面、修正費と料金内訳は計算と説明の2列、料金は比較カード、FAQは左右に分けた見出しと開閉項目、相談は数字とアイコンを組み合わせた終端とする。

- ホームの本文は `home-content`、章は `home-section` で区切り、専用CSSを `styles/home.css` に置く。共通の `theme.css` に束ねるが、他ページに作用する無指定セレクターは追加しない。
- 広い器1280pxをホーム専用のトークンに追加。共通の1104px、図解、配色の意味、価格データは維持する。
- `Section` に任意の `id` / `className` を追加。未指定時は従来のHTMLを保つ。
- ページ内ナビの文言は日本語カタログ、行き先は `href` で生成。FAQと料金切替は既存のHTML/CSSを使用する。
- 図解4点のHTMLと全説明文を保持する。Lucideの本文アイコンは31個から45個へ増加し、行き先と修正内容を示す。外部依存・画像・実行時JSは追加しない。

## 検証

型・構造・文言・lint、単体112件、ビルド、全21ページの静的・ブラウザ検査を実施。幅320〜1440pxで表示、アンカーの位置、料金切替、FAQのキーボード操作を確認。既存図解のHTMLとテキストノードに欠落がないことを変更前後で比較する。端末実機のSafariは未検証。
