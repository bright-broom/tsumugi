# 0011 — 月140時間の料金体系をサイトと事業資料へ採用する

2026-09-14 / 採用。ADR 0010の判断モデルをもとに、ユーザーがプロジェクトへの反映を指示した。本番公開と既存契約の変更は含まない。

## 決定

制作は79,800円 / 198,000円 / 398,000円、任意の継続支援は0円 / 4,800円 / 9,800円 / 29,800円（月額）、すべて税別。公開価格の唯一の正本を `site/src/content/prices.ts` に保ち、月次の作業枠・外部費概算・着手割合もここで管理する。社内モデルの写しと価格・作業枠が一致することをテストする。

自社24回分割・通常変更の無制限・撮影込みを新規商品から外す。制作は着手50%・検収50%、継続支援は前月末の申し出で翌月変更。増築の充当は同一事業・再利用可能・12か月以内・1回を条件とする。CMS付き商品は「受付準備中」を表示し、提供確認前に申込みを受けない。

変更枠は月合計を5分単位で切り上げ、依頼ごとの切り上げと繰越は行わない。追加課金は自動で行わず、超過前に次月対応か別見積もりを選んでもらう。仕様不適合の修補は通常変更の枠と分ける。

価格だけでなく、ホーム・FAQ・契約下書き・法務表示・業種別・変更範囲・図解・補助金例・OGPを同期する。旧 `/unlimited.html` はリンク互換のため残し、表示名を「変更と継続支援」にする。制作カードは2列、継続支援はPCで2×2、狭い画面では1列。既存のアイコンとホームの4図解を維持する。

比較は「守る」と外部費概算3,500円/月を含め、不利な1ページの行も表示する。変更を含む「整える」で6ページを持つ総額も示し、役務の差を説明する。税込の掲載費比較では紬側も税込にする。

## 資料と生成物

ビジネスガイドライン、料金方針、採算モデル、Excelの写しを同期。プラン廃止と支払方法変更によりExcelの制作・支援・配布用シートの列構成と算式を改め、他シートの補助金の算式は維持して価格参照を更新する。青い入力・参照式の色など既存の書式を踏襲する。Excelはサイトを更新する入力元ではない。

全21枚のOGPに入口価格が入るため再生成した。一時出力先で確認し、料金に関係しないファビコンは変更していない。生成環境はmacOSの既存フォント設定とPlaywright Chromium。フォントを新規に追加・変更していない。

## 検証と限界

型・構造・文言・スタイルの検査、lint、単体122件、経営モデル9件、全項目603 PASS / WARN 1 / FAIL 0（静的358 PASS）。分割切替の撤去などで実在する検査対象が5件減った。しきい値は変更していない。

静的出力の21ページを幅320・390・1440pxで確認し、横はみ出し・旧入口価格・実行時JSなし。料金・ホーム・掲載費の画面とOGPを目視確認した。ExcelはLibreOfficeで再計算し、数式エラー・未計算値なし、公開比較総額と月84時間の枠の一致を確認する。標準のマクロ再計算がタイムアウトしたため、隔離したプロファイルでXLSX変換を用いて再計算した。

既知のWARNは仮の事業者情報。フォーム、保守の提供体制、CMS、契約文面の確定は残課題。価格の反映はそれらの機能完成を意味せず、月商や利益を保証しない。
