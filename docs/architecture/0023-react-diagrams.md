# 0023 — 図解を型付き React / SVG に移す

日付：2026-09-15。状態：採用。関連：[#56](https://github.com/bright-broom/tsumugi/issues/56)、[改善計画 #55](https://github.com/bright-broom/tsumugi/issues/55)。

## 背景

図解 6 種類は `content/diagrams.ts` が HTML / SVG の文字列を生成し、`Figure.tsx` が正規表現で外枠を取り出して `dangerouslySetInnerHTML` へ渡していた。構造は TypeScript の JSX 検査を通らず、文言はモジュール読込時のカタログに固定されていた。矢印の ID はラベルのハッシュで決まり、同じ図を 1 ページに複数置くと衝突した。

## 決定

- `components/diagrams/` に、所有比較、掲載費の振替、契約期間の比較、ポータル経由の流れ、補助金の内訳、補助金の手順の 6 コンポーネントを置く。利用側は名前付き props で金額・期間・日付を渡す。
- `Figure` は型付きの描画要素、説明、代替説明、viewBox、狭幅用の描画を受け取る。HTML 文字列の受け口と正規表現による分解を廃止し、React に要素・属性・テキストのエスケープを任せる。
- `primitives.tsx` に枠・見出し・矢印・共通の SVG 属性をまとめる。幾何情報は SVG 属性、意味を持つ色は既存のグローバルテーマを使う。独立した CSS やライブラリは追加しない。
- 図解の文言は `i18n/locales/ja/diagrams.ts` に保ち、`pageProps → ContentProvider → useMessages('diagrams')` で受け渡す。ローカライズ済みの文字列や料金を描画部品へ複製しない。不要になった `figure` エラーカタログを削除する。
- 各 SVG キャンバスが React の `useId` に基づく矢印 ID を持ち、描画中の Context で矢印に渡す。モジュール内の可変な通し番号や文字列置換は使わない。同じ図を複数置いても独立し、同じ React ツリーの再描画では同じ出力になる。
- 図解ごとに必要な矢印の種類だけを宣言して `<defs>` を出す。使用しない定義は配信せず、未定義の矢印を使うとビルド時の描画でエラーにする。

Context と `useId` は静的生成時にだけ動く。Pages Router と実行時 JavaScript 0 バイト、既存ルート、料金計算、和欧文の半角スペース、全図解の内容と配置を維持する。

## 出力差分の理由と互換性

React は SVG の空要素を閉じタグ付きで書き出す。矢印 ID の生成方式と未使用の矢印定義の削除も変わるため、図解を含む 5 ページは HTML のバイト列が変わる。これは生成方式の変更として、AGENTS.md の例外条件に従って検証する。

- 全 50 ファイルのうち 45 ファイルは変更前と SHA-256 が一致する。
- 変更された `index.html`・`owned.html`・`price.html`・`cost-cut.html`・`subsidy.html` は、figure の外側の HTML が完全に一致する。
- 矢印 ID を対応付け、未参照の矢印定義だけを除外して比較すると、SVG の要素・属性・文字と計算済みの配置・書体・色が一致する。
- 同じ Chromium で、5 ページ × 幅 1440 / 390 / 320 px の全ページ画像を比較する。15 条件すべてで PNG のバイト列が一致し、視覚差分はない。
- TOP の HTML は 102,051 → 101,081 バイト。未使用定義を削除することで、100 KiB の検査基準を引き上げずに維持する。

画像と比較結果はローカルの `.artifacts/diagrams-react/` に保存する。繰り返しビルドによる出力の一致と、通常の型・lint・テスト・ビルド・静的検査・ブラウザ実測も確認し、結果は [status.md](../status.md) に記録する。

## 今回の境界

この決定で図解の HTML 文字列生成を解消する。`raw()` を使う装飾本文、JSON-LD のシリアライズ、フォント設定とメニューの操作方針は別の責務であり、#56 全体の完了を意味しない。後続の UI 調整も、この型付きの描画と既存の i18n を基盤に進める。
