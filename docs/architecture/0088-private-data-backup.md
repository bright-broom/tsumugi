# 0088 業務データ（.data/）を 1 つの暗号化ファイルにまとめてバックアップする

- 日付：2026-09-26
- 状態：採用（保管先・世代・鍵の保管はオーナーが決める。#103 の E1）

## 背景

社内ツールの実データ（顧客・案件・見積・請求・入金・振込先の設定）は `.data/` にあり、顧客の情報を含むので git 管理外に置く決まり（[ADR 0036](0036-internal-ops-tools-and-estimates.md)）。週次のバックアップ（[ADR 0045](0045-weekly-backup.md)）はリポジトリの中身だけを対象にしているため、**`.data/` はどこにも写しがなく、オーナーの端末 1 台にしかなかった**。端末の故障・紛失で、請求と入金の記録（帳簿として 7 年の保管を約束している情報を含む）を失う。

保管先（外付けディスクか、オーナー名義のクラウドか）はオーナーの判断で、まだ決まっていない。ただ、どの保管先を選んでも「暗号化した 1 ファイルにまとめ、戻せることを確かめる」道具は要る。

## 判断

`npm run backup:private`（`tools/ops/private-backup.ts`・`cli/private-backup.ts`）を足す。

- **形式**：`.data/` の通常のファイルを、ファイルごとの SHA-256 つきの一覧にして gzip し、AES-256-GCM で暗号化した 1 ファイル（`tsumugi-data-<日時>.tsmg`）。鍵はパスフレーズから scrypt（既定 N=2^17、r=8、p=1）で作る。ヘッダー（形式・鍵の作り方・salt・iv・作成日時・ファイル数）も認証の対象（AAD）にし、書き換えを検出する。Node の標準の暗号だけを使い、依存を増やさない。
- **パスフレーズ**：環境変数 `TSUMUGI_BACKUP_PASSPHRASE` だけで受け取り、12 文字以上を求める。引数では受け取らない（シェルの履歴・プロセス一覧に残る）。
- **作成**：社内ツールと同じロック（[ADR 0072](0072-local-ops-command-lock.md)）を取って読むので、書きかけの状態を写さない。書いたあとに読み戻して復号し、全ファイルの SHA-256 を照合してから成功とする。ロックと書きかけの一時ファイルは写さない。リンクがあれば写さずに止める（中身の所在が変わりうるため）。
- **取り出し**：空の（またはまだない）フォルダにだけ書く。今あるデータを上書きしない。フォルダの外へ書くパス（`..`・絶対パス）と、SHA-256 の合わない中身は取り出さない。
- **世代**：`prune --keep N` が、このコマンドの名前の形のファイルだけを古い順に消す。既定の 12 は、週 1 回で約 3 か月。プライバシーの説明の削除（契約に至らなかった方は 1 年）をバックアップでも守る目安。
- **保管先**：決めない。`--out` で毎回指定する。`.data/` の中は拒否する。リポジトリの追跡対象の場所も拒否する（既存の `resolveOutputFile`）。

## 限界

- パスフレーズをなくすと戻せない。鍵の保管（パスワード管理ツール、2 人目も取り出せること）はオーナーの運用。
- 自動では動かない（端末の中のデータなので、GitHub Actions では作れない）。週 1 回の実行は、オーナーの端末の定期実行（カレンダーの予定、launchd など）で行う。
- 暗号化はファイルの中身と名前を守るが、ファイルの大きさと作成日時（ファイル名）は隠さない。
- ファイル 1 つにまとめて丸ごとメモリで扱う。社内ツールのデータ（JSON）の規模では問題ないが、写真などの大きな素材を `.data/` に置く運用には向かない。

## 検証

- `tests/ops-private-backup.test.ts`（7 件）：まとめて暗号化 → 復号 → 空のフォルダへ取り出して全ファイルが一致、中身が平文で読めないこと、ロックと一時ファイルを写さないこと、違うパスフレーズ・本文の改ざん・ヘッダーの改ざん・形式違いを拒否、正しい鍵で細工した中身（フォルダの外へのパス・SHA-256 の不一致）を拒否、リンク・空でない取り出し先・短いパスフレーズを拒否、世代の整理が自分の名前の形だけを対象にすること。CLI を別プロセスで動かし、作成（読み戻しの照合）→ 照合 → 取り出し → 世代の整理、パスフレーズなし・保管先がデータの中・他の操作の実行中（ロックあり）・違うパスフレーズで終了コード 1。
- 既定の鍵の強さ（N=2^17）で、架空の 200 ファイルの作成（読み戻しの照合を含む）が約 1.2 秒、取り出しが約 0.9 秒。取り出した中身は元と `diff -r` で一致し、ファイルの権限は 600、フォルダは 700。
