# 0089 本文を短くし、手順は図・並列の要点はアイコン付きカードで見せる

- 日付：2026-09-26
- 状態：採用

## 背景

オーナーから「全体の文字が多い。より簡潔に書き直し、アイコン化・図解化してほしい。デザインは高品質に」と依頼があった。各ページには、同じ内容を表と文章で2回書いた箇所、注記を2つ3つ重ねた箇所、1問の答えが3文ある質問などが残っていた。

一方で、短くすると事業の規範（[ビジネスガイドライン](../business/紬_ビジネスガイドライン.md) 9.x：できないことを先に書く・測っていない数字を書かない・負けている比較の行を消さない・境界を同じ場所に書く）や、検査が求める語（`verify` 26「借地・所有・名義・ソースコード」、29 価格、30 比較の出典）を落としやすい。

## 判断

1. **同じことは1回だけ書く。** 表と同じ内容のカード、図と同じ内容の開閉リストは片方を削る（例：所有の4要素はアイコン付きカードだけにし、同じ対照表を削る。補助金の手順は既存のタイムライン図だけにする）。
2. **注記は1つにまとめ、1〜2文にする。** 答え・説明は原則1文。
3. **短い手順（3〜6段）は `StepRail` の図にする。** アイコン・番号・線で順番を見せ、補足は1行の小見出しにする。820px 未満は縦に並べる。手順ごとの長い説明と「だれが・いつ」が要るもの（制作の流れ）は、既存の `Flow` を使う。
4. **並列の要点（3〜5点）はアイコン付きカードにする。** アイコンは各項目の意味を区別できるものだけ選ぶ。すべて同じ「チェック」のアイコンは使わない（業種ページの「掲載する内容」は項目ごとのアイコンに替えた）。注意喚起の `Note` のアイコン（状態を示すものだけ。原則E）は変えない。
5. **削らないもの。** 借地と所有の表、法律上の借地権との違いと「弁護士ではない」旨、比較の出典と負けている行、準備中・検討中の表示、「保証しません」「いきなりやめません」などの境界。検査やテストが文言を固定しているもの（例：飲食店の比較の「制作費別。任意の支援と外部費を税込で比較」）はそのまま残す。
6. **対象外。** 規約・特商法・個人情報のページは、弁護士の確認と公開条件（本文の SHA）に結びついているため変えない。FAQ の答えは開閉の中にあり、表示される文字にほとんど影響しないため今回は変えない。

## 結果

表示される文字（`<main>` の中。図の中の文字と、閉じた開閉の中身は除く）を、主要18ページで 30,274 字 → 24,125 字（−20.3%）にした。減りが大きいのは、owned −36%、source −40%、cost-cut −34%、subsidy −33%、TOP −24%。

- 新しい共通部品：`src/components/StepRail.tsx`（スタイルは `src/styles/components/steps.css`）。カードの4列（`g4`）を `cards.css` に足した。
- 見た目を変える変更なので、`out/` のハッシュ一致（AGENTS.md 4-4）は対象外。PC（1440px）とモバイル（390px）の画面で確認した。

## 限界

- 文字数は目安で、読みやすさそのものは測っていない。
- 事業の文言（価格の説明・保証しないことの書き方）を短くするたびに、ガイドライン 9.x と検査の両方を確かめる必要がある。
