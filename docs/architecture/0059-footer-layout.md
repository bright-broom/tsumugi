# 0059 — フッターの連絡先と目的別案内を整理する

日付：2026-09-17。状態：採用。

## 課題と決定

フッターの会社情報に連絡先が混在し、案内の 3 グループが縦積みになっていた。問い合わせページと共通のメール用クラスも影響し、メールアドレスだけが過度に大きく表示されていた。

- 上段はエスプレッソ色の相談帯。明朝の呼びかけと電話・メールを左右に配置し、スマートフォンでは読み順に縦へ並べる。メールは直接 `mailto:` を開く。電話番号、土日を含む受付時間、メールの 24 時間受付を中央の設定から表示する。
- 下段はアイボリーの案内。会社情報に続き「サービスを知る・費用を確かめる・相談や依頼を進める」を PC で 3 列にする。モバイルでは最初の 2 グループを横に並べ、最後のグループを全幅の 2 列にする。
- 業種別リンクを独立した横列へ移し、法定リンクと注意書きは下部にまとめる。既存の 20 ページへの案内、現在地表示、先頭へのリンクを保持する。
- 電話・メール・住所に冗長な見出しを追加しない。Lucide の線画を残し、下位リンクごとの矢印を削減する。住所の読み上げ用ラベルは保持する。
- メールはフッター専用クラスに分ける。最小文字サイズ 14 px、リンクの高さ 44 px 以上、暗い背景に明るいフォーカス枠を確保。動きを減らす設定では矢印を動かさない。

## 採用と実装

共通 frontend-design ガイド 1.0（2026-09-14）を適用。導入済みの React 19.3.0、Next.js 16.3.5 Pages Router、Tailwind 4.3.3 と Lucide React 1.45.0（公式 npm `lucide-react`、lockfile 固定）を継続する。既存アイコンを再利用し、新規依存・素材・外部通信は追加しない。静的リンクと中央管理の CSS だけで実装するため、実行時 JavaScript 0 を維持できる。

文言・金額・契約条件は変更せず、既存 i18n と設定の正本を参照する。自動コントラスト検査の対象を、廃止した相談ボタンから新しいメールリンクへ置き換えた。検査の合格基準は維持する。

## 検証と限界

- 型・lint・Vitest 518 件・料金モデル 12 件・ビルド・セキュリティ検査が合格。全 21 ページで実行時 script 0 件。
- 静的プレビュー：PASS 318 / WARN 1 / FAIL 0。本番モード全項目：PASS 581 / WARN 3 / FAIL 0。WARN は既存の専門家・受入確認の未実施。
- 全 21 ページ × 幅 320 / 390 / 768 / 1024 / 1440 px の 105 組み合わせで、はみ出し、リンク先、操作領域、文字サイズ、先頭へのキーボード移動を確認。5 幅で実画像を確認し、メールのキーボードフォーカスも確認した。
- 検証画像・ログはローカルの `.artifacts/footer-layout/` に保存。フッター全体の比較画像のみ固定ヘッダーと固定バーを除いて撮影し、通常の画面画像も別途確認した。

Chromium での検証であり、実機 Safari・問い合わせ率への効果は未確認。GitHub push、Vercel の本番反映・プラン変更はこの作業に含めない。
