# ADR 0008: アイコンを豊富に使った共通フッター

- 日付: 2026-09-14
- 状態: 採用

## 背景

利用者から、フッターを多数のアイコンを使って美しくし、ヘッダー・本文に合うデザインに刷新することが指定された。従来は暗い面に小さな文字のリンクを縦に並べていた。

## 決定

全21ページのフッターを `components/Footer.tsx` に分離する。相談への入口、ブランドと連絡先、サービス案内、業種別案内、大きな欧文ブランド文字、規約・注意書き・著作権表示の順に構成する。既存の明るいグレーと黒、ヘッダーの明朝を使い、本文のチャコールから区切りを作る。

- CSSの正本は `styles/footer.css`。古いフッター指定とホーム側の個別上書きを削除して一元化する。
- ブランド・連絡先・注意書きは既存カタログと設定を使用する。追加文言は `shell.footer`、遷移先はルート登録を参照する。
- 主要13ページと業種別4ページ、法務3ページへのリンクを保持。現在地を `aria-current` で示す。
- 連絡先・案内・業種・法務・操作にLucideアイコンを32個配置する。狭い画面では業種カードの装飾矢印4個を隠し、表示は28個になる。装飾アイコンは読み上げず、リンクには文字を残す。
- 電話はアイコンと番号の共通部品を維持。HTMLアンカーでページ先頭へ戻る機能を追加する。実行時JS・外部フォントは追加しない。
- 大きな欧文ブランド文字は重複した装飾のため `aria-hidden` にする。連絡先は `dl`、案内と規約は別の `nav` にする。

## 検証

型・文言・lint・単体テスト・ビルド・全21ページの静的およびブラウザ検査を実施。新しいフッターの電話・問い合わせ・ナビ・先頭移動にコントラスト検査を追加する。幅320〜1440pxで横はみ出し、44px以上の操作領域、キーボードでの先頭移動、ページ遷移と現在地を確認する。端末実機のSafariは未検証。


## 2026-09-17：アイコンで分かる補助ラベルを省く

ユーザー指定によりフッターの「電話受付」「メール（24 時間受付）」「所在地」を視覚表示から除き、時間・メールアドレス・郵便番号と住所をアイコンの隣へ配置。ラベル列を 70 px から 20 px に縮める。電話番号と発信先は共通 PhoneLink を維持する。メールアドレスは @ の前で改行可能にし、狭幅で末尾だけが折り返されるのを避ける。メールの 24 時間受付は問い合わせページと全体メニューで引き続き案内する。

同様に、電話番号に隣接する問い合わせページの「お電話」とメニューの「電話受付」を整理。先頭移動は上向き矢印だけにし、44 px 以上の操作領域とアクセシブル名を保持する。法定表示の表見出しや、アイコンだけでは行き先を判別できないナビゲーションは文字を使う。

既存 Lucide と CSS を使用し、追加パッケージはない。視覚的に省いた定義語と見出しは読み上げ用に残し、Tailwind の sr-only を中央の globals.css で明示生成する（自動クラス探索は引き続き無効）。日本語カタログを参照する構成を維持し、未使用になった header.hours は削除。

検証：型・lint・Vitest 484 件・料金モデル 12 件・ビルド成功。最終ビルドの全項目 verify は PASS 575 / WARN 1 / FAIL 0。Chromium・JS 無効、幅 1440 / 768 / 390 / 320 px でラベル非表示、連絡先・リンク・郵便番号の保持、横はみ出しなし、先頭移動と操作領域を確認。PC と 320 px のフッター画像も目視。既存の本番公開条件は変更しない。
