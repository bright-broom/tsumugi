# 0057 — TOP を料金・用途から読み進められる構成にする

日付：2026-09-17。状態：採用。

## 課題

幅 390 px の TOP は、料金セクションの開始まで約 6,268 px のスクロールが必要だった。所有・更新・納品条件を説明する節が繰り返され、準備中の管理画面付きプランも複数の大きな枠で案内していた。相談の締めくくりは飲食店の掲載費・予約手数料に偏り、メール受付にもかかわらずフォームの文言が残っていた。

## レイアウトと導線

- ヒーローの画像・コピーは保持し、PC の高さを 680 px までにする。画像内に文字を収める構造を維持。
- ヒーロー直後にページ内案内を配置。冒頭で制作費・任意の保守・外部実費の関係と、メール相談・料金への導線を示す。
- 本文の順序を「サービス紹介 → 料金 → 業種 → 所有 → 総額比較 → 更新 → 補助金 → FAQ → 相談」に変更。
- 料金は 1 ページの制作内容を主役にし、6 / 9 ページは価格・規模・制作期間の短い一覧にする。受付準備中の状態も保持。詳しい条件は料金ページへ。
- 所有の図を表示したまま、重複する納品内容はネイティブの details にまとめる。3 点の図解（所有・期間比較・補助金）を保持。
- 紬の比較欄は生成りの面と琥珀の細い線で区別する。比較期間・外部費・更新範囲の注記と全プランの表は保持する。
- 全業種に通じる相談案内へ変更し、主なメール CTA は指定のメールアドレスを直接開く。
- CSS は既存の中央管理 Tailwind に限定し、削除したセクション専用の規則も整理。和文の字間・見出しの改行・幅ごとの段組みを調整する。

## 採用したもの

共通 frontend-design ガイド（2026-09-14 版）を参照。React / TypeScript、Tailwind 4.3.3、導入済み lucide-react 1.45.0 の静的 SVG を継続使用する。取得元は既存 package-lock.json の npm 公式パッケージ。新しい UI ライブラリ・外部素材・フォントは導入しない。ネイティブのリンクと details で実装でき、実行時 JavaScript 0 バイトを守れるため。文言は ja/home.ts、価格は content/prices.ts の正本から取得する。
