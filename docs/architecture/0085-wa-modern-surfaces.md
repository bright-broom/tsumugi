# 0085 明暗の帯・明朝の見出し・金の罫で、和の世界観を全ページに通す

- 日付：2026-09-25
- 状態：採用（実機・支援技術での確認は未実施。main 反映は status.md 参照）

## 背景

オーナーから「和風で進めているが全体のまとまりが弱い。訪れた瞬間の『すごい』が無い」という指摘があった。実際の画面を見ると、原因は配色や書体そのものではなく**世界観が最初の1画面で終わっていること**だった。

- ヒーローだけが日本画と明朝で作り込まれ、スクロールした先はアイボリー一色・1px 罫線の箱・同じ大きさの見出しが続く事務的な面に切り替わる。
- 3色の面積配分（アイボリー 70／エスプレッソ 20／琥珀 10、[ADR 0014](0014-three-color-system.md)）のうち、**サブのエスプレッソが本文側でほとんど使われていない**。明暗の差が無いので、章の切り替わりも分からない。
- 商品の中心である価格（100,000 円）が本文と同じ強さで置かれている。
- ページごとに導入の作りが違い（濃い面・明るい面・独自のヒーロー）、サイトとしての一貫性が無い。

方向性は 3 案（和モダン×ダーク／エディトリアル・ミニマル／モダン・コントラスト主導）を示し、オーナーが**和モダン×ダーク**と、構成の調整まで含める範囲を選んだ。

## 判断

**面（surface）と余白で章を組み、線と箱を減らす。** 色の原値（3 色）と文言・料金・URL は変えない。

- **明暗の帯**：`section.dark` を奥行きのあるグラデーション（`ink-deep` → `ink`）と上下の金の細線を持つ「帯」にする。TOP は 暗→明→明（沈み）→明→暗→明→暗→明→暗 の順で、明るい面が 3 つ続く区間を作らない。
- **導入はすべて濃い帯**：`Section` の `h1` の章を既定で `dark` にし、どのページもヒーローと同じ面で始まる。明るい導入にしたい章だけ `tone="tint"` を渡す。
- **見出しは明朝**：`h1`・`h2` を屋号と同じ端末の明朝（`font.family.brand`、weight 600）にする。`h3`・`h4` は情報の粒なのでゴシックのまま。外部フォントは足さない。
- **数字を主役にする**：価格・総額は明朝の特大（`font.size.figure-*`）で、琥珀は下線（`box-shadow: inset`）か金の文字だけに絞る。面いっぱいの琥珀（旧・相談の章）はやめる。
- **箱を減らす**：囲み罫の代わりに、ごく薄い沈み（`ink-veil`）・金の細線・余白で区切る。表は外枠を外し、見出し行を沈んだ面と琥珀の細線で締める。章の区切りの罫線も外し、余白（96px）に置き換える。
- **織り目**：屋号（紬＝織物）にちなみ、明るい面に 2〜3% の濃さの織り目を敷く。画像ファイルは足さず、`repeating-linear-gradient` 2 本で作る。濃い面と絵の上では出さない。
- **濃い面に載る部品**：ページ内索引・プラン比較の 3 段・問い合わせの連絡先・FAQ の索引・料金の面に、濃い面用の配色を用意する。**明るいカードが濃い帯に載るときは、章の白い文字を受け継がず墨に戻す**（この取りこぼしが実際に読めない文字を生んだ）。
- **濃い帯に載る図は「図版」**：図解はアイボリーのまま金の細枠で囲み、面から浮かせる（図内の文字の読みやすさを保つ、ADR 0014 の方針どおり）。

新しい色は増やさない。`gold`・`gold-soft`・`ink-deep`・`ink-veil` は、いずれも 3 色からの混色として `design.tokens.json` に定義する。

## 限界

- **実機・支援技術での確認は未実施**。明朝の見え方は端末の書体に依存する（macOS は Hiragino Mincho ProN W6、Windows は Yu Mincho、Android は Noto Serif CJK の合成）。weight 600 を指定しているため、W6 を持たない環境では合成太字になる。
- ブラウザ実測を含む `npm run verify` は、この作業環境ではローカルの待受が禁止されていて実行できない。代わりに 22 ページ × 1280/375px を DOM 上で走査し、コントラスト（AA）・横あふれを確認した（下記）。LCP の再計測は別途必要。
- OGP 画像は書体環境の条件があるため再生成していない（[ADR 0047](0047-og-image-environment.md)）。共有カードの意匠は今回の対象外。
- 図解そのもの（線の太さ・配色）は変えていない。濃い帯の上では図版として囲むに留める。
