# 0048 店舗情報・連絡導線・掲載許可を静的テンプレートに接続する

- 状態：採用（2026-09-16）
- 関連：PR #67、Issue #19〜#22
- 前提：Pages Router、React、TypeScript、中央管理の Tailwind CSS・i18n、公開ページの実行時 JavaScript 0 バイトを維持する。

## 問題

`claude/template-store-cta` は店舗情報・スタッフ・お客様の声・連絡導線のモデルと部品を追加した途中で止まっていた。`about.tsx` の未使用変数 6 件で型検査が停止し、その後の検査にも不要な export と React の key 不足が残っていた。PR #68 が先に main に入ったため、カタログと静的ページ入力にも競合が生じた。

## 構成

- `content/store.ts` の店舗設定から、所在地・営業時間の表示と JSON-LD を作る。臨時営業は同じ基準日で抽出し、過去の案内を両方から除く。静的サイトなので、日付の更新には再ビルドが必要。
- 来店を受ける拠点がある場合だけ、about に `StoreInfo` を表示する。紬の既定値では表示しない。
- `publishedStaff` と `publishableTestimonials` を通してから描画する。非公開・退職・許可の撤回・未承認の改稿を扱い、許可の記録識別子は公開用データから落とす。スタッフ・声の写真も同意に応じて表示する。
- 声の依頼・謝礼の条件から表示文を決める。名前や写真の許可とは別に扱い、必要な表示を消すための props は設けない。
- `CONTACT_PRESETS` と設定済みの行き先から CTA を選ぶ。予約・LINE が未設定なら問い合わせ・電話に代替し、同じ窓口を重複させない。ラベルは窓口の種類から選ぶ。
- 内部だけで使う型・整形関数の export を整理する。公開条件や外部掲載情報の照合など、検証の入口は回帰テストで確認する。
- 共通文言を固定ページとコレクションページの両方に渡し、main の検証レポート・コレクション用 OGP 対応を保持する。

## UI の採用記録

既存の `Section`・カード・表・`Note`・`PhoneLink`・`Icon` を再利用した。配色と余白は既存 Tailwind CSS 4.3.3 の中央スタイル、アイコンは既存の公式 npm パッケージ `lucide-react` 1.45.0。依存関係・アイコンセット・実行時スクリプトは追加しない。表示ラベルは `i18n/locales/ja/storefront.ts` に置く。

共通デザインガイドの README / GUIDELINES（2026-09-14 版）に従い、既存部品を優先した。新規ライブラリの選定は行っていない。
